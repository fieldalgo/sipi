# SIPI workbench 후보

[English](README.md)

[프로젝트 흐름](PROJECTS.ko.md)은 기존 폼 19종의 입력 변형과 **Saved analysis**의
저장 실행 이력을 지원한다. 프로젝트와 개별 환경 파일은 사용자가 직접 내보내며
자동 원격 저장을 하지 않는다.
[실행 결과 연결](RECEIPTS.ko.md)은 저장 계산을 해당 입력 설정에 묶는다.
[설치 파일 helper](ARTIFACTS.ko.md)는 호스트 출처용 실제 배포물 파일을 수집한다.
[계산 기록](RECORDING.ko.md)은 설치 wheel 또는 staged 브라우저의 **Saved analysis → Run and keep record**에서 원문 결과 기록과 실행환경 목록을 내보낸다.
[Windows 후보 기록](FROZEN_RECORDING.ko.md)은 풀린 실행파일·번들을 식별하며 해당 정확 Windows 빌드와 smoke 통과가 수락 조건이다.
[브라우저 기록](BROWSER_RECORDING.ko.md)은 같은 기록 전달에 검사된 staged 배포 원본을 사용한다.

독립 설치한 SIPI 엔진을 기본 브라우저의 로컬 화면 또는 브라우저 Worker에서
실행하는 소스 후보입니다. 출시된 앱은 아닙니다. Windows x64는 설치 없는
단일 EXE가 목표이며 Python·엔진·화면을 포함하고 별도 브라우저 엔진이나
원격 계산 서비스를 포함하지 않습니다. 실제 용량과 Windows 동작은 성공한
Windows 빌드·실행 보고서로 확인해야 합니다. wheel 크기는 EXE 크기가 아닙니다.

기본 화면은 단면 입력 폼 19종, 저장된 메시 설정, 목표 임피던스, 공차 샘플,
단면 JSON 저장과 선로·회로 결과를 제공합니다. **Saved analysis**에서는
[`sipi.execution`](../docs/locales/ko/pages/packages/sipi/execution.md)에 등록한
고정 엔진의 등록 계약 원문 JSON을 열고 검증·정규 저장·실행·결과 내보내기를 합니다.
실패한 공차 행과 목표 역산 이력도 보존하며 불완전한 공차 결과의 요약은
계산하지 않습니다. 선택한 특성/모드 진단이 실패해도 기본 선로 결과는 남습니다.
입력 변경·취소 시 기존 결과의 표시·내보내기를 무효화합니다. 모든 계약의
전용 입력 폼까지 구현한 것은 아닙니다. 명시적인 메시를 담은 유한 영역 3D
정전용량 입력은 저장한 절연 경계·도체 순서를 유지해 전체 C(F)를 반환합니다.
기하 편집기·비아 전이 L/S·열린 공간 프린징까지 지원한다는 뜻은 아닙니다.

## 하부 접지판 없는 코플래너 폼

**Unbacked coplanar**는 신호 하나와 유한폭 양측 접지 도체를 가지며 하부
접지판은 없습니다. 기판 위와 아래에 공기가 있고 외곽은 유한 영역의 절연
경계입니다. 방사 경계 모델은 아닙니다. gap은 신호 바닥 가장자리와 접지
사이 거리이며 신호만 테이퍼되고 접지 도체는 직사각형을 유지합니다.

**Domain bounds**에서 하부 공기는 자동(기판 높이의 10배) 또는 명시 높이로
설정합니다. 검사·고정은 다른 입력과 고정 메시를 보존합니다. 편집 JSON,
단위 전환, 프로젝트 변형은 원 물리값을 유지합니다. 하부·상부 공기와 외곽
폭은 수렴 확인용 영역 설정이며 기본 제조 공차 변수에 추가하지 않습니다.
gap과 접지 폭은 기존 고정 nominal 메시 정책으로 표본 계산할 수 있습니다.

진공 고정 메시 예제는 폭 0.5 mm, gap 0.2 mm, 접지 폭 1 mm, 기판 0.5 mm,
유전율 1, 두께 0, 상부·하부 공기 각 12 mm, 외곽 폭 24 mm입니다.
메시는 edge 1 µm, far 0.25 mm, growth 0.1이며 독립 유한 접지 자유공간
기준 목표는 115.58150659942925 Ω입니다. 폭 범위 0.4–0.6 mm, 허용 1 Ω에서
요청 메시와 세분 메시의 잔차를 모두 확인합니다. 이 정밀 예제는 native에서는
완료했지만 브라우저 역산은 5분 제한에 걸렸으며 실패로 보존합니다. 별도 명시
메시 예제(edge 4 µm, far 0.5 mm, growth 0.2)는 같은 기하·목표·폭 범위·1 Ω
잔차 기준과 독립 세분을 사용합니다. 실패 뒤 앱이 메시를 자동 교체하지 않습니다.
이전 자동 폭 역산 정책은 edge와 growth를 목표 탐색 전에 다시 세분해
같은 넓은 영역의 강제 세분 단계에서 30만 점 제한에 걸렸습니다. 이 폼의
자동 폭 역산은 이제 factory가 정한 edge와 growth를 유지하고 far만 4로
나눕니다. 독립 세분과 두 잔차 검사는 그대로 수행합니다. 명시 메시와 다른
폼의 정책은 유지합니다. 실패 후 자동으로 바꾸는 대체 경로가 아니며 점 수와
시간 제한을 늘리지 않습니다. 앞의 정밀 명시 메시 브라우저 실패는 별도로 남습니다. 실제 재료·기하·요구 정확도에
맞춰 메시와 외곽 영역 수렴을 따로 확인해야 하며 자동 크기나 역산 성공만으로
물리 정확도를 확정할 수 없습니다.

## 표본 행을 CSV로 내려받기

지원하는 `sipi.impedance-study/4` 계산 뒤 **Save sample table CSV**를 누르면 모든
표본 행을 원래 순서로 내려받습니다. 입력 스키마, 임피던스 종류, 행 번호,
순서대로 나열한 변수, 임피던스(Ω), 계산 결과를 열로 제공합니다. 화면의 7자리
반올림 대신 계산에서 보고한 숫자의 정밀도를 보존합니다. 실패한 임피던스는
빈칸이며 실패 이유도 유지합니다. 행을 삭제하거나 집계 통계를 새로 만들지 않습니다.

**View saved run**으로 과거 실행을 보면 **Save saved-run samples CSV**가 해당
기록을 내보냅니다. 현재 입력을 바꾸거나 재계산하지 않습니다. 현재 폼에 미적용
설정이 있어도 명시적으로 연 과거 실행의 CSV는 내보내며 미적용 설정은 보존합니다.
과거 기록 파일명은
`sipi-saved-study-samples.csv`, 현재 결과는 `sipi-study-samples.csv`입니다.
입력이나 미적용 설정을 편집하면 내보내기를 초기화합니다. 미지원 결과에는 CSV
버튼이 없고 계산 중이거나 종료한 상태에서는 내보내지 않습니다. CSV는 표를
활용하기 위한 기능입니다. 전체 입력·실행 설정·출처는 JSON 실행 기록과 환경
파일을 함께 보관하세요.

파일은 BOM이 있는 UTF-8, 쉼표 구분, 따옴표로 감싼 텍스트와 CRLF 행을 사용합니다.
스프레드시트 수식 접두어나 일부 제어 문자로 시작하는 텍스트에는 작은따옴표를
앞에 붙이고, 숫자 셀은 숫자 그대로 유지합니다. 쉼표·따옴표·개행은 이스케이프하며
원문은 JSON에 보존합니다. 모든 스프레드시트의 해석을 인증하는 기능은 아닙니다.


## 두 재료의 네 코너 조합

**Saved analysis**에서 **Four material corner combinations**를 선택해 두 변수의
하한·상한과 평가 주파수를 편집합니다. `sipi.impedance-study/4`의 두 변수 corners
형식에서 같은 재료의 서로 다른 주축에 지정한 상수 상대유전율을 지원합니다.
설명에는 변수 순서와 축이 표시되며 입력의 변수 순서를 뒤집어도 그대로 보존합니다.
다른 바인딩과 형식은 JSON에서 편집합니다.

**Apply settings**는 원본과 후보를 검증한 뒤 적용합니다. 저장된 변수 순서에 따라
두 하한·상한의 네 조합을 모두 계산하며 무작위 seed나 표본 수는 없습니다.
유효하지 않은 재료 코너는 전계 계산 전에 거부합니다. 계산 실패 행은 유지하고
집계 통계를 제공하지 않습니다. 표시된 극값은 이 네 점의 값이며 범위 내부의
극값이나 제조 수율을 보장하지 않습니다. 기하, 회전각, 손실, 메시와 실행·프로젝트
기록의 기존 계약을 유지합니다.


## 상하한을 지정하는 균일 재료 공차

**Saved analysis**에서 **Bounded uniform material tolerance**를 선택하거나 단일
변수 `sipi.impedance-study/4` uniform 입력을 여세요. 하한·상한, 표본 수(2–128),
정수 seed(0–4294967295), 평가 주파수를 편집합니다. **Apply settings**는 원본과
후보 입력을 검증한 뒤 적용하며, 유효하지 않은 재료 범위는 원본을 바꾸지 않습니다.
상수 상대유전율 또는 Debye 강도 하나를 지원하며 다른 바인딩은 JSON에서 편집합니다.

같은 seed와 입력으로 같은 표본을 재현합니다. 균일 표본은 지정한 입력 범위를
사용하지만, 유한한 무작위 표본만으로 출력의 극값이나 제조 수율을 보장하지 않습니다.
범위가 무한한 정규분포와 구분합니다. 샘플러, 기하, 메시, 재료 극점과 실패 행은
유지합니다. 계산 실패는 원래 행에 남으며 집계 통계를 제공하지 않습니다.
현재 설정, 프로젝트 복원과 과거 실행 기록은 서로 구분하여 보존합니다.


## 저장한 설계를 다시 편집하기

템플릿을 선택하고 치수·재료를 입력한 뒤 **Save editable design**을 누릅니다.
**Open design**으로 내려받은 JSON을 열면 입력 폼이 복원되어 수정·계산·목표 폭
역산·공차 검토를 계속할 수 있습니다.
[`sipi.template-section/1`](../docs/locales/ko/pages/packages/sipi/template_document.md)은
원래 템플릿 인수와 확정 기하·메시를 함께 보존합니다. 열 때 현재 엔진으로 같은
기하가 재생성되는지 확인하며, 불일치하거나 지원하지 않는 파일은 현재 설계를
바꾸지 않고 거부합니다.

폼은 microstrip, stripline, offset stripline, coupled microstrip, coupled stripline, grounded coplanar,
coupled grounded coplanar, planar coated microstrip, planar coated pair, coated grounded coplanar, coupled coated grounded coplanar, unbacked coplanar, coupled unbacked coplanar, coated unbacked coplanar(single/pair), normal-film microstrip(single/pair), normal-film grounded coplanar(single/pair) 19종입니다. 나머지 엔진 템플릿은 **Saved analysis**를 이용합니다.
임의 기하에서 치수 폼을 추정하지 않습니다. **Export geometry**는 기존 단면 JSON을
내려받으며, 이 기하 파일을 다시 열면 기하·메시는 보존하지만 치수 편집은 켜지지 않습니다.

**Offset stripline**은 두 접지면 사이의 단일 신호선에 바닥면 높이를 직접 지정하는
별도 폼입니다. 중앙 배치 **Stripline**과 구분하며 높이는 필수 값으로, null 자동값을
사용하지 않습니다. 전체 접지면 간격에는 도체 두께가 포함됩니다. 간격이나 두께를
바꿔도 지정한 높이는 고정되며 도체 전체가 두 접지면 안에 있어야 합니다.
그림·편집 JSON·A/B 프로젝트·고정 메시가 같은 입력을 유지합니다. 목표는 z0이고
주파수 결과는 단일종단 2포트입니다. **Bottom-face height**로 높이 공차를 계산할 수
있으며 기존 중앙 배치 파일을 자동 변환하지 않습니다.

단일선 검증은 균일 유전체의 얇은 도체에 대해 독립 평행 접지면 Green 패널 기준,
메시·횡방향 외곽·수직 반사를 따로 확인합니다. 유한 35 µm 직사각 도체는 같은 메시의
독립 복소/진공 유한요소 계산과 비교합니다. 폭 역산은 요청·세분 메시의 허용 오차를
모두 만족해야 합니다. 임의 배치·재료 또는 실측 PCB 정확도 전체를 보증하는 검증은 아닙니다.

**Coated unbacked coplanar**와 **Coated unbacked pair**는 유한 기판 위에
전체 폭의 평면 코팅을 추가합니다. 코팅 높이는 기판 표면부터 구리를 포함한 높이이며
구리 두께보다 커야 합니다. 상부 공기는 코팅 위에서, 하부 공기는 기판 아래에서
시작합니다. 뒷면·중앙 접지는 추가하지 않습니다. 신호는 테이퍼를 쓸 수 있고 양쪽
유한 접지는 직사각형입니다. 코팅의 유전율·손실탄젠트는 별도 입력이며 정밀한
코팅·계산 영역 값은 단위 변경·편집 JSON·프로젝트 변형에서 유지됩니다.

단일 폼은 스칼라 임피던스·2포트, 같은 폭의 차동 쌍은 차동 임피던스·4포트를
사용합니다. 코팅 높이·유전율과 접지 치수는 공칭 메시를 고정한 공차 연구에
사용할 수 있습니다. 코팅이 구리에 닿는 공차 범위는 전계 계산 전에 거부합니다.
자동 폭 역산은 factory의 가장자리·성장률을 유지하고 외곽 메시를 세분한 뒤
독립 세분 검사를 수행하며 두 메시 모두 목표 오차를 만족해야 합니다.
독립 중성 자유공간 패널·유한 코팅의 메시/외곽 수렴·복소 P1 에너지·코팅이 공기가
되는 극한을 따로 검증합니다. 법선 두께의 conformal 코팅을 의미하지 않는 평면
모델이며, 임의 재료·실측 제조 정확도를 보증하지 않습니다. 기본 주파수 폼의
quasi-TEM·명시 직렬 저항 모델 한계도 동일합니다.

**Unbacked coplanar pair**는 같은 폭의 신호 두 개와 양쪽 유한 폭 직사각
접지를 사용하며 뒷면 접지면·중앙 접지가 없습니다. **Gap**은 신호 아랫면 사이,
**Signal–ground gap**은 바깥 신호 끝과 접지 사이 간격입니다. 테이퍼는 신호에만
적용합니다. 하부 공기는 기판 높이의 10배 자동값 또는 지정값이며 단위·편집 JSON·
선택 메시 저장·A/B 프로젝트에서 유지됩니다. 제조 공차 변수가 아닌 수치 계산 영역입니다.
상부·하부 공기와 횡방향 외곽은 메시 세분과 별도로 수렴을 확인해야 합니다.

폭 역산과 간격·접지 공차는 차동 임피던스를 사용합니다. 자동 역산은 factory의
가장자리 크기·성장률을 유지하고 외곽 메시를 세분한 뒤 요청·독립 세분 메시가 모두
목표 허용 오차를 만족해야 합니다. 명시 메시 설정은 그대로 유지합니다.
폭 0.5 mm·신호 간격 0.3 mm·접지 간격 0.2 mm 진공 예제의 독립 유한 접지 패널
목표는 181.05076148507075 Ω입니다. 모드별 메시·외곽 수렴과 유한 구리의 복소 에너지
대조는 해당 예제의 검증이며 임의 기하나 실측 제조 정확도를 보증하지 않습니다.
주파수 내보내기는 single-ended 4포트와 기존 mixed-mode 응답을 보존하며,
같은 quasi-TEM·지정 직렬 저항 모델의 한계를 따릅니다.

**Coupled stripline**의 plane spacing은 두 접지면 사이 전체 거리이고 gap은
구리 아랫면 모서리 사이 간격입니다. 두 도체는 같은 아랫폭과 단면 형상을 사용합니다.
목표·공차 연구는 차동 임피던스이며 주파수 응답은 single-ended 4포트와 mixed-mode
표현을 함께 보존합니다. **Vertical placement**에서 중앙 배치 또는 명시적 `trace_height`를 선택합니다.
높이는 아래 접지면부터 구리 바닥면까지의 거리입니다. 구리 전체가 두 접지면
사이에 있어야 합니다. 정밀한 저장 높이는 그림·mm/µm/mil 변경·폭 편집·고정 메시·
프로젝트 변형에서 유지됩니다. 중앙 배치로 돌아가면 기존 nullable 값으로
명시적으로 저장하며 JSON 형식을 바꾸지 않습니다.

명시 높이는 접지면 간격이나 구리 두께를 바꿔도 고정됩니다. 중앙 배치는
`(plane_spacing - thickness) / 2`를 따릅니다. 폭 역산도 배치를 유지합니다.
명시 배치일 때 공차·스윕에 **Bottom-face height**를 사용할 수 있고,
중앙(null) 높이는 수치 공차 변수로 취급하지 않습니다. 범위가 어느 접지면이든
닿거나 넘으면 전계 계산 전에 거부합니다. 이 조작부는 coupled-stripline에만
적용하며 중앙 단일 stripline을 다른 템플릿으로 자동 변환하지 않습니다.

검증한 균일 유전체·0두께 선로 조건에는 독립 평행판 Green 함수 패널 계산,
중앙 단일 선로의 타원적분 한계, 별도 메시·외곽·수직 반사 검사를 사용합니다.
35 µm 직사각형 쌍은 같은 메시에서 독립 복소/진공 유한요소 대조도 수행합니다.
이 기준이 일반적인 실측 PCB 정확도나 모든 배치·재료의 정확도를 보장하지는 않습니다.

더 세밀한 메시의 목표 검사에
실패하면 거친 결과를 수락하지 않고 평가 이력을 보존합니다. 목표 결과의 저장 문서는
요청한 메시를 사용하며 별도의 refined 임피던스는 검증값이고 저장 메시를 대체하지 않습니다.

**Coupled coplanar**는 바닥 접지면 위의 같은 신호 도체 두 개와 유한 폭의 양옆
접지 도체입니다. **Gap**은 신호끼리 아랫면 모서리 간격이고 **Signal–ground gap**은
각 신호와 옆 접지의 아랫면 모서리 간격입니다. **Ground width**는 각 직사각형
옆 접지의 폭입니다. 접지는 신호와 같은 두께이며 taper는 신호에만 적용합니다.
폭 역산과 공차는 차동 임피던스, 네트워크 내보내기는 신호 4포트를 사용합니다.
두 접지 치수의 공차를 지정할 수 있고 단일 신호 coplanar에서도 접지 폭 공차를
지원합니다. 가져온 air height·box width는 정확히 보존하며 Domain bounds에서 조절합니다.
유한 접지 치수를 바꾼 뒤 메시와 외곽 영역 수렴을 각각 확인해야 합니다.
이 쌍의 자동 폭 역산은 접지 간격을 이미 반영한 기본 edge size·growth를 유지하고
far size만 4분의 1로 줄인 뒤 별도 세분화 검사를 수행합니다. 명시한 메시 설정은
바꾸지 않습니다. 세분화 결과가 지정 오차를 벗어나면 메시를 확인·세분화한 뒤
다시 실행해야 하며 점수 한도나 목표 오차를 완화하지 않습니다.

폼의 독립 기준은 두께 0인 진공 도체의 image-charge panel 계산입니다. 메시 세분화와
유한 외곽 확대를 따로 확인하며 유한 두께 또는 제조 실측 정확도로 확대하지 않습니다.
서로 다른 신호 치수나 독립 접지 두께는 **Saved analysis**의 별도 엔진 계약을 사용합니다.

폭 목표의 행렬 출력은 별도 세분 검사가 통과한 뒤 선택한 요청 메시의 계산 결과를
재사용합니다. 같은 메시를 다시 풀지 않으며 두 실행 환경은 이를 지원하는 엔진으로
고정합니다. 입력·이력·수치 기준은 그대로입니다. 중복 풀이 한 번을 없애는 변경이며
모든 명시적 메시가 실행 제한 시간 안에 끝난다는 보장은 아닙니다.

표시 단위를 바꾸어도 저장된 SI 입력을 반올림하지 않습니다. 수정하지 않은 인수와
화면에 없는 air height·box width 등은 그대로 유지합니다. 필드를 수정하면 표시된
결과를 무효화합니다. 목표 역산이 성공하면 실제 반환된 폭과 메시를 저장합니다.
다시 연 설계를 수정해도 저장된 메시가 유지되므로 바뀐 기하의 메시·외곽 수렴을
별도로 확인해야 합니다. 다른 템플릿을 선택하면 기본 설정으로 새 설계를 시작합니다.
편집 설계 파일에는 입력만 들어가며 결과·목표 범위·공차 설정·A/B 프로젝트 이력은
포함하지 않습니다.

고정 엔진의 등록 입력은 109종입니다. 등록·정규화가 모든 계산의 브라우저 적합성,
작업 한도 충족 또는 독립 정확도 검증을 뜻하지 않습니다. 편집 경로는 native와
Worker의 공통 어댑터를 사용하지만 실제 고정 엔진·자산으로 플랫폼별 검증해야 합니다.
핀 변경만으로 Windows나 Worker 통과를 주장하지 않습니다.

## 표시 단위와 물리 입력

**Coated coplanar pair**는 유한 옆 접지 사이의 같은 신호선 두 개입니다.
**Gap**은 신호 도체끼리 아랫면 모서리 간격이고 **Signal–ground gap**은 바깥
신호 모서리에서 옆 접지까지의 별도 간격입니다. 신호 테이퍼는 접지 단면을
바꾸지 않습니다. 평면 코팅·공기 여유 정의는 단일 코팅 coplanar와 같습니다.
목표·공차는 차동 임피던스를 사용하며 단일종단 4포트와 mixed-mode 응답을
보존합니다. 두 간격·접지 폭·코팅 치수를 고정 기준 메시로 분석할 수 있습니다.
자동 폭 역산은 확정 edge/growth를 유지한 뒤 기존 세분 검증을 수행하며 명시
메시는 그대로 둡니다. 독립 image-panel·복소 FE·메시/외곽·공기 극한 검증은
명시한 대칭 기하의 근거이며 실측 제조 정확도 보증은 아닙니다.

단면 길이와 폭 범위는 mm, µm, mil로 표시할 수 있습니다. 단위를 바꿔도 SI 기하,
목표 역산의 폭 범위, 길이 공차 범위는 그대로입니다. 명시적으로 편집한 물리 값만
갱신하며 표시 반올림이 반대쪽 경계를 덮어쓰지 않습니다. 재료 경계는 무차원입니다.
공차 변수를 바꾸면 현재 기준 입력에서 물리 범위를 다시 정하며 표시 단위에 영향을
받지 않습니다.

빈 구리 두께는 단위를 바꿔도 유효한 0으로 바뀌지 않습니다. 얇은 도체 모델을 쓰려면
`0`을 직접 입력하세요. 빈 공차 경계도 계속 거부합니다. 목표·공차 설정은 현재 탭의
조작 값이며 입력 프로젝트에 새로 저장되는 것은 아닙니다. 주파수 응답의 선로 길이는
별도로 표시한 mm 입력이고 메시 확인은 항상 µm입니다.

## 유한 계산 영역 설정과 확인

**Domain bounds**에서 계산 영역의 실제 폭과 전체 높이를 계산 없이 확인합니다.
표면 템플릿은 공기층 높이도 표시하며 stripline에는 공기 높이 조작부가 없습니다.
가져온 기하 파일은 읽기 전용으로 확인합니다. 단면 그림은 잘라낸 개략도이고
유한 계산 외곽의 실제 크기를 그린 그림이 아닙니다.

**Set width** 또는 **Set height**를 고르면 현재 mm/µm/mil 단위로 box 폭이나 공기층
높이를 직접 입력합니다. 이미 확인한 값이 있으면 명시 모드의 시작 값으로 사용합니다.
다른 원래 인수와 기존 고정 메시를 유지하며 단위 전환으로 저장된 SI 값을 반올림하지
않습니다. **Automatic**은 해당 치수를 기존 템플릿 기본값으로 돌리므로 기하를 바꾸면
자동 외곽도 바뀔 수 있습니다. 새 자동 요청은 선택 인수를 생략하고 기존 템플릿 파일
정규화가 기본 null을 채웁니다. 저장된 null과 정확한 명시 값은 파일 열기와 A/B 입력
프로젝트에 보존합니다. 외곽 크기를 제조 공차 변수에 추가하지 않습니다.

확인만 하면 표시된 결과를 유지하고 외곽 치수를 수정하면 기존 결과를 지웁니다.
외곽 확대와 메시 세분화의 결과 변화를 각각 비교해야 합니다. 구리를 담을 수 없는
작은 폭은 거부하며 크기 변경만으로 수렴을 인증하지 않습니다. 평면 코팅의 공기
높이는 코팅 위 공기층의 두께이고 기판 표면부터 잰 코팅 높이와 다릅니다. 외곽을
수정해도 저장된 메시를 유지하므로 새 영역에서도 적합한지 다시 확인해야 합니다.

## 메시 확인과 세분화

**Mesh settings**를 열고 **Inspect current mesh**를 누르면 계산하거나 입력을
바꾸지 않고 현재 메시 설정을 확인합니다. 길이는 기하 표시 단위와 별개로 항상
마이크로미터입니다. 확인이나 일반 계산만으로 자동 메시가 고정되지는 않습니다.

**Refine mesh ×2**는 edge size, far size, growth를 절반으로 줄인 고정 메시를
명시적으로 선택하고 minimum angle은 유지합니다. 기존 결과를 지우므로 다시
계산하여 수렴을 비교해야 합니다. 정확도를 인증하거나 외곽 영역을 바꾸는 기능은
아닙니다. 고정 설정은 기하 편집·단위 변경·편집 파일·A/B 입력에 유지됩니다.
**Use automatic mesh**는 고정 설정과 기존 결과를 지웁니다. 자동 목표 역산은
기존의 더 촘촘한 시작 메시와 별도의 세분화 검사를 유지합니다. 저장 파일에는
확정 설정이 들어가고 다시 열면 고정 메시로 복원됩니다. 기하 전용 가져오기는
확인만 가능하며 이 조작부로 설정을 바꾸지 않습니다.

## A/B 단면 입력을 프로젝트로 유지하기

**Duplicate design**을 누르면 현재 단면을 보존하고 복사본을 수정할 수 있습니다.
**Current design**으로 전환할 때 떠나는 설계의 변경 입력을 유지합니다.
**Design name**은 이름을 바꿉니다. 템플릿 선택이나 편집 설계 열기는 현재 변형의
단면을 바꿉니다.

**Save input project**는 `sipi-project.json`을 내려받습니다. **Open project**는
첫 설계를 복원하며 선택 목록으로 다른 설계를 엽니다. 입력 검사만 수행하고 자동
계산하지 않습니다. **Planar coated pair**는 동일한 두 신호선의 바닥 모서리 간격과 선택적인 공통
사다리꼴 단면을 입력합니다. 코팅은 두 선의 옆과 위를 평탄한 윗면까지 채우며,
높이는 기판 표면부터 구리 두께를 포함해 잽니다. 구리보다 높아야 하고 **Air height**는
코팅 위의 공기층 높이입니다. 기판과 코팅의 유전율·손실탄젠트는 별도입니다.
폭 역산·공차 값은 `z_diff`이며 주파수 결과는 단일종단 4포트와 혼합모드입니다.
코팅 높이·유전율 공차의 전체 경계에서 구리와의 여유를 먼저 검사합니다.
표시 단위·고정 메시·JSON·프로젝트 변형은 원래 물리 입력을 보존합니다.

이 쌍의 자동 폭 역산은 코팅을 반영한 기본 edge size와 growth를 유지하고 far size만
4분의 1로 준비한 뒤, 기존의 별도 세분 메시 검증과 점수 제한을 적용합니다.
명시 메시 설정은 유지합니다. 얇은 진공 선로의 독립 image-panel 기준, 유한 사다리꼴
도체의 독립 복소 정전용량 조립, 메시·공기/폭 수렴, 코팅을 공기로 바꾼 극한을
검증합니다. 일반적인 실측 제조 정확도나 conformal coating 지원을 뜻하지 않습니다.

**Coated coplanar**는 유한 폭의 직사각형 접지 두 개 사이에 신호선 하나를 두고,
아래쪽 기준면과 전체 폭의 평탄 코팅을 사용합니다. **Gap**은 신호선 바닥 모서리부터
접지 모서리까지의 간격이며 **Ground width**는 각 접지의 폭입니다. 신호선에만
사다리꼴 단면을 적용하고 접지는 직사각형을 유지합니다. 코팅 높이는 기판부터
구리 두께를 포함하며 공기층은 코팅 위에서 잽니다. 목표·공차 값은 `z0`, 네트워크는
단일종단 2포트입니다. 코팅 높이·유전율, 간격·접지 폭을 고정 nominal 메시와
전체 경계 사전검사로 표본화합니다. 자동 폭 역산은 코팅을 반영한 edge/growth를
유지하고 far size를 4분의 1로 준비하며 기존 필수 세분 검증을 그대로 수행합니다.
명시 메시는 유지합니다. 독립 image-panel·복소 FE·메시/외곽·공기 극한 검증은
실측 제조 정확도나 conformal film 검증과 구분합니다.

표시 단위를 바꿔도 원래 SI 값·숨은 템플릿 설정·확정 메시를
유지합니다. 계산·역산은 각각 모델 및 수렴 기준을 별도로 만족해야 합니다.

프로젝트에는 단면 기하·재료·메시를 저장합니다. 목표 범위·공차 옵션·주파수 응답
설정과 화면에서 새로 계산한 결과는 추가하지 않습니다. 기존 파일에 검증된 결과
기록이 있으면 보존하지만 입력 변경 시 현재 선택을 해제하고 복제본은 빈 이력으로
시작합니다. 이전 기록을 새로 계산한 결과처럼 표시하지 않습니다.

모든 설계가 현재 편집 폼 19종 중 하나여야 합니다. 지원 외 입력·손상된 프로젝트·
200 KiB 초과 파일은 현재 프로젝트를 바꾸지 않고 거부합니다. 인코딩한 요청 한도는
256 KiB이며 초과 수정은 잘라내지 않고 거부합니다. 기하만 담은 파일은 활성 편집
프로젝트 설계를 대체하지 못합니다. 편집 설계나 별도 작업창을 사용하세요. 취소는
대기 중인 파일 읽기와 늦은 응답도 무효화합니다. 내려받기 전 프로젝트는 이 탭에만
있으며 자동 파일 저장·복구·클라우드 저장은 제공하지 않습니다. 오류 후 입력을
고쳐 재시도하거나 저장한 프로젝트를 다시 열 수 있습니다.

## 소스 실행

설치한 개발 SIPI wheel에도 이 로컬 UI와 어댑터가 들어갑니다. `sipi` 또는
`sipi gui`로 실행하고, URL만 표시하려면 `sipi gui --no-browser`를 사용합니다.
[설치 UI 안내](../docs/locales/ko/pages/packages/sipi/local_ui.md)를 참고합니다.
wheel 빌드가 같은 원본을 복사하며 브라우저·외부 런타임을 번들하지 않습니다.
소스·editable 체크아웃은 아래 직접 실행기를 계속 사용할 수 있습니다.

`packaging/engine-ref.txt`의 SIPI와 해당 엔진 `dependencies.json`에 고정한
galerkin·meshine을 설치하고 `packaging/requirements-windows.txt`의 수치 패키지를
사용합니다. 다른 editable 소스 경로가 설치본을 가리지 않도록 합니다.

```sh
python workbench/desktop/main.py
```

임의의 localhost 포트를 열어 기본 브라우저를 실행합니다. 세션 토큰은
URL fragment/세션 저장소에 보관하며 Host·Origin·API 토큰을 검사합니다.
호스팅용 서버가 아닙니다. **Exit**으로 종료하며 탭을 닫는 것만으로 서버가
종료되지는 않습니다. 자동화에서는 `--no-browser`로 로컬 URL만 출력합니다.
요청은 256 KiB, 저장 입력은 200 KiB, 공차/역산은 128회 평가, 작업은 5분으로
제한합니다. 전체 메모리·출력 크기 제한을 보장하는 것은 아닙니다. 취소하면
계산 프로세스 또는 Worker를 중단합니다.

로컬 HTTP 호스트는 응답을 보낸 뒤 송신을 종료하고, 읽지 않은 소켓 입력을
최대 1초·1 MiB까지만 버립니다. 일반적인 초과 요청에서 오류 응답이 연결
리셋으로 사라지는 것을 막되, 허용 입력 256 KiB 제한을 늘리거나 멈춘 송신자를
무한히 기다리지 않습니다. 연결을 끊거나 무한히 전송하는 상대에게까지 응답
전달을 보장하지는 않습니다. Windows 후보 smoke는 실제 초과 요청의 오류
응답을 확인한 뒤 계산·정상 종료·임시 파일 정리를 검사합니다.

## 로컬 Worker 준비·검증

엔진·공유 패키지의 정확한 고정 커밋에서 깨끗한 체크아웃을 준비하고
setuptools/wheel을 설치합니다. 준비 단계는 공식 자산 다운로드가 필요합니다.
archive/lock 해시, 자체 wheel, 고지·출처·런타임 목록을 보존하며 새 출력 폴더를
사용합니다.

Git attributes로 Windows에서도 원본 고지의 바이트를 보존합니다. 고지 원문이나
해시 검사 기준을 바꿔 불일치를 감추지 않습니다.

```sh
python workbench/packaging/browser.py --engine ENGINE_CHECKOUT --shared SHARED_CHECKOUT --output .validation/web
python -m pytest -q workbench/tests
node --test workbench/tests/*.test.mjs
node workbench/tests/browser.mjs .validation/basic-native
node workbench/tests/saved-browser.mjs .validation/saved-native
node workbench/tests/browser.mjs .validation/basic-worker .validation/web
node workbench/tests/saved-browser.mjs .validation/saved-worker .validation/web
```

실제 브라우저 시험에는 Chromium/Chrome과 WebSocket을 지원하는 Node가 필요합니다.
`SIPI_PYTHON`·`CHROME`으로 실행 파일을 선택할 수 있습니다. 준비 후 시험에서는
계산 자산을 로컬에서 읽습니다. 재배포 검토가 끝나기 전에는 준비된 제3자 바이너리를
공개 호스팅에 복사하지 않습니다. 이 후보에는 호스팅·라우팅 변경이 없습니다.

화면 동작 수락과 수치 일치는 별개입니다. Native와 Worker의 SciPy·Shapely·GEOS가
다릅니다. 타원 쌍 사례에서 native 메시 996점/1754삼각형, Worker 995점/1752삼각형으로
C0 norm 차이가 약 1.03e-5였습니다. CODATA 2022 고정 이후 동일 메시를 재사용한
검증 사례의 정전용량·표면 응답 상대 차이는 1.14e-15 이내였습니다. 모든 재메시·결과의
점별 일치를 뜻하지 않으며 기존 허용 오차는 유지합니다. 엔진의 물리 모델 범위도
유지합니다. 국소 개구 정전용량은 완전한 3D 전이 모델이 아닙니다.

## 비교 기준 결과 유지

단면 계산에 성공하면 **Keep current as baseline**으로 현재 결과를 비교
기준에 고정합니다. 실제 기하·메시·엔진 정보와 결과를 별도로 복사합니다.
치수, 계산 영역 또는 메시를 바꾸고 다시 계산하면 두 값을 비교할 수 있습니다.
**Clear baseline**은 기준을 지우며, 새 결과를 명시적으로 고정하면 기존 기준을
교체합니다. 기하·메시 상세에서 어떤 입력과 수치 설정이 달라졌는지 확인하세요.

신호가 1개 또는 2개이고 이름과 순서가 같아야 비교합니다. 도체 대응을 자동
추정하지 않습니다. 양쪽에 있는 유한 스칼라 값과 C·L·1GHz의 G 행렬 각 원소를
표시 단위로 비교합니다. 비대칭 쌍은 대칭 모드 요약값을 만들지 않고 행렬만
비교합니다. 변화량은 현재값−기준값이며 백분율의 분모는 기준값의 절댓값입니다.
기준이 0이면 백분율은 없습니다. 비유한 행렬이나 표시 차이의 오버플로는 거부합니다.

입력을 바꾸거나 계산이 실패·취소되면 현재 차이는 숨기고 기준은 유지합니다.
표시 단위 변경은 결과를 바꾸지 않습니다. 좁은 화면에서는 임피던스를 다른 요약값
위에 배치하고, 비교표는 패널 안에서 가로로 스크롤합니다. 기준은 이번 탭에서만 유지하며 입력
프로젝트에 저장되지 않고 새로고침하면 사라집니다. 실행 이력을 영구 보존하려면
Saved analysis 기록을 사용하세요. 이 표는 네트워크 곡선·공차 행을 비교하지
않으며, 작은 차이 하나로 메시·외곽 수렴이나 실측 정확도를 인증하지 않습니다.

## Windows 후보 검증

topic 전용 `workbench-candidate.yml`은 정확한 자체 wheel 설치·adapter 검증·설치 파일
대조 후 CPython 3.13.17/Nuitka 2.8.10/설치된 Visual Studio 2022로 빌드합니다.
보고서·고지만 업로드하고 EXE·제3자 런타임 바이너리는 업로드하지 않습니다.
독립 및 SciPy 내부의 NumPy 호환 계층은 FFT·선형대수 모듈을 동적으로 불러옵니다.
고정 빌드는 이 4개 모듈을 명시적으로 포함하고 설치본 동작과 완료된 컴파일 보고서의
실제 포함 여부를 검사합니다. 포함 검사만으로 EXE 실행을 통과했다고 판단하지 않습니다.
같은 준비를 마친 Windows 환경의 명령은 다음과 같습니다.

```sh
python workbench/packaging/windows.py
python workbench/packaging/smoke.py .validation/sipi-windows/FieldAlgo-SIPI.exe
```

`inventory.json`에는 정확 버전·컴파일러·wheel 해시·native 파일·실제 EXE 용량/해시가
기록됩니다. `build-info.json`은 내장되어 계산 결과에도 들어갑니다. `smoke.json`은
한글·공백 경로의 첫 실행·계산·종료·임시파일 정리를 측정하고 실패 시 실패 보고서를
남깁니다.
기록 실행 두 번, 살아 있는 추출 번들의 독립 hash 대조, 원문 프로젝트 추가/조회도
종료 전에 확인합니다.
로컬 URL을 출력하기 전에 종료되어도 stdout/stderr를 크기 제한·세션 토큰 가림과
함께 보존합니다.
`--no-browser` 시험이므로 Windows 10/11의 대화형 기본 브라우저 실행,
망 차단 검증, 서명과 전체 native/static 재배포 검토는 별도 관문입니다.
단일 EXE 목표를 ZIP·온라인 런처로 대체하지 않습니다.

[의존성 버전·조건](THIRD_PARTY.ko.md)을 참고하세요.

## 저장 목표의 메시 한도

브라우저와 무설치 후보는 `packaging/engine-ref.txt`의 정확한 엔진을 사용합니다.
저장 임피던스 목표가 메시 점수 한도를 넘으면 완료 이력, 실패 파라미터,
탐색/세분 단계, 확정 기하·메시와 선택 재료를 실패 결과에 남깁니다.
Saved analysis 화면에서 실패 결과를 내보낼 수 있고 실행 기록·프로젝트도
실패 계산을 다시 실행하지 않고 보존합니다. 성공 설계로 취급하거나 자동 재시도·
메시 완화를 하지 않습니다. 다른 솔버 오류·취소·시간 초과는 기존 동작을 따릅니다.
후보별 실제 플랫폼 빌드·실행 근거가 필요하며 엔진 고정값 변경만으로
Windows 검증이나 출시 검증을 마쳤다고 판단하지 않습니다.

## 저장 입력의 재료 목표

**Saved analysis**에서 `sipi.impedance-design/3` 재료 목표 문서를 열고 입력을
검사한 뒤 실행하여 입력·결과 JSON을 내보냅니다. 선택한 재료 스냅샷과 탐색·세분
이력은 결과에 함께 남습니다. 고정 엔진은 한 탐색 안에서 같은 기하의 메시와
진공 정전용량을 재사용하고, 재료별 계산과 필수 세분 메시 생성은 별도로 합니다.
평가 예산이나 수치 수락 기준은 바뀌지 않습니다.

실제 브라우저 검증에는 native·Worker의 상수 유전율 및 Debye 강도 stripline
역산이 포함됩니다. 입력·결과 내보내기, 선택 모델과 이력, 상대 1e-10 이내의
수치 일치와 원래 목표 허용값인 양쪽 메시 잔차 1Ω 이내를 검사합니다. 실행 계약
검증이며 실측 기판 정확도나 일반적인 속도 보장이 아닙니다. 폭이 바뀌면 보통
새 메시가 필요하며 기존 작업 한도도 유지합니다.

## 두 재료 목표와 재료 공차 분석

**Saved analysis**에서 `sipi.pair-impedance-design/2`와
`sipi.impedance-study/4` JSON도 열고 검사·계산한 뒤 입력과 결과를 내보낼 수
있습니다. 두 목표 역산은 선택한 두 재료값과 요청·세분 결과를 보존합니다.
공차 분석은 표본 재료와 실패 행을 모두 남기며, 한 행이라도 실패하면 통계가
미완료 상태입니다. 한 분석 안에서 같은 재료 기하의 메시를 재사용하되 각 재료
전계는 다시 계산합니다. 별도 호출은 빈 캐시로 시작합니다.

브라우저 검증은 native·Worker에서 고정 기하의 대각 텐서 두 목표와 상수·Debye·
상관 텐서·유효/무효 정규 표본을 실행합니다. 두 목표는 요청·세분 모두 원래의
100/34Ω 목표 및 1/.5Ω 허용값을 충족해야 합니다. 두 최적화 실행의 선택 재료값은
상대 1e-4, 임피던스는 1e-5 이내로 비교합니다. 반복 이력은 달라도 모델·기하·
예산·세분의 내부 일관성을 유지해야 합니다. 공차 수치는 상대 1e-10 또는 절대
1e-14 이내이며 입력·행 순서·실패 상태를 보존합니다. 내보낸 결과는 실제 실행과
같아야 합니다. 기존 단일 목표 기준은 유지합니다. 이 제한된 실행 검증은 실측
정확도·일반 최적화 수렴·공차 메시 자동 수렴을 보장하지 않습니다.

## 예제로 저장 분석 시작하기

**Saved analysis**에서 시작 예제를 고르고 **Load example**을 누릅니다.
RLC 회로, 상수·Debye 재료 목표, 차동·공통 두 목표, 유전율 sweep, 상관 재료
공차 분석을 제공합니다. 선택만 하면 설명이 바뀌고, 불러오기를 눌러야 입력을
교체하고 이전 결과를 지웁니다. 기존 프로젝트 이력은 보존됩니다. 입력값을
수정하고 검사·계산한 뒤 입력·결과 또는 프로젝트를 저장하여 나중에 이어갑니다.
계산 중이거나 종료한 뒤에는 불러오기가 비활성화됩니다. 제한된 시작 입력이며
모든 엔진의 시각 편집기나 수정한 기하·재료의 정확도 보장을 뜻하지 않습니다.

## 재료 분석 결과 읽기

저장된 단일·두 변수 재료 목표는 선택 입력값과 요청·세분 메시의 목표값·임피던스·
잔차·허용값을 나누어 표시합니다. 재료 공차 분석은 원래의 0부터 시작하는 행 번호,
표본 입력값, 임피던스 또는 보존된 오류를 보여줍니다. 모든 행이 성공할 때만 엔진이
반환한 표본 통계를 표시하며, 실패가 섞인 결과로 부분 통계를 만들지 않습니다.
화면은 입력 문서의 단위를 사용하고 유효숫자 7자리로 반올림합니다. 원본 JSON·
내보내기·기록에는 보고된 전체 값이 그대로 남습니다.

과거 재료 기록을 열면 **Saved run** 표시와 함께 그 기록의 결과를 보여줍니다.
현재 입력이 달라도 과거 표의 계산값을 바꾸지 않습니다. 입력 수정·취소·새 실행은
이전 표를 지웁니다. 지원하지 않는 스키마·오류, 표시할 수 없는 구조는 기존
원본 JSON 보기로 남습니다. 표시는 읽기 전용이며 추가 해석이나 통계 계산을 하지
않습니다.

## 재료 목표 입력하기

상수 또는 Debye 재료 목표 예제를 불러오면 **Material target settings**가
나타납니다. 목표값·허용 오차(Ω), 양수인 탐색 하한·상한, 평가 주파수(Hz),
평가 횟수(3–128)를 수정할 수 있습니다. `sipi.impedance-design/3`의 단일 상수
상대유전율 또는 Debye 강도 바인딩을 지원하며, 다른 목표 입력은 JSON 방식으로
유지됩니다. 폼 위에서 물리량·재료 영역·탐색 변수를 확인합니다. 기하·재료 pole·
메시·고정 치수는 바꾸지 않습니다.

**Apply settings**를 누르기 전에는 임시 편집값입니다. 이때 현재 설계의 검사·
계산·저장은 비활성화되고, **Reset form**으로 현재 JSON의 값을 복원합니다.
적용 시 기존 엔진으로 원본과 수정 문서를 모두 검사하며 해석을 실행하지 않습니다.
잘못된 입력이면 JSON은 그대로입니다. 적용에 성공하면 JSON과 검사 상태를
갱신하고 이전 결과를 지우며, 프로젝트 이력은 보존합니다. 이후 계산·기록·저장·
재열기를 할 수 있습니다. 다른 입력을 불러오면 미적용 편집값은 교체되며 과거
기록은 바뀌지 않습니다. 작업 중·종료 후에는 폼을 잠급니다. JSON을 직접 수정하면
진행 중인 폼 적용의 오래된 응답을 받지 않습니다. 재료 모델의 유효범위와 요청·세분
목표 검사는 계속 적용되며 새 최적화 방법이나 정확도 보장을 추가하지 않습니다.

## 임피던스 목표 실패 확인하기

저장된 단일 변수 임피던스 목표가 실패하면 **Impedance target not accepted**를
표시합니다. 요청한 목표·탐색 구간과 완료된 모든 평가를 보여주고 search/refinement
단계를 구분합니다. 마지막 행은 수락된 해답이 아닙니다. 메시 제한으로 중단한
시도는 완료 이력과 별도로 표시하며 임피던스 값을 만들어 넣지 않습니다. 완료된
평가가 0개인 경우도 명시합니다. 화면이 값을 다시 계산하지 않습니다.

기존 scalar design 스키마 1–3의 정의된 목표·메시 실패 계약만 지원합니다. 다른
오류나 잘못된 표시 구조는 원본 JSON으로 남습니다. 과거 실패를 볼 때는 그 기록을
사용하고 현재 입력을 바꾸지 않습니다. 입력 수정이나 성공한 재실행은 이전 실패
표시를 지웁니다. 실패 기록은 프로젝트 이력과 내보내기에 그대로 남으며 수치 목표
허용 오차·메시 제한·실행 시간 제한을 바꾸지 않습니다.

## 재료 스윕 입력하기

**Dielectric sweep**을 불러오거나 단일 상수 유전율·Debye 강도 스윕 파일을 열면
**Material sweep settings**가 나타납니다. 유한한 표본 하한·상한(하한 < 상한),
표본 수(2–128), 평가 주파수(Hz)를 입력합니다. **Apply settings**는 기존 엔진으로
원본과 수정한 `impedance-study/4` 입력을 검사한 뒤에만 교체합니다. 재료·끝점
검사에서 범위를 거부하면 원본은 그대로이며 값을 제한하거나 다시 뽑지 않습니다.
기하·재료 pole·메시·물리량·표본 방식은 문서에 유지됩니다.

임시 편집값은 적용하거나 초기화할 때까지 계산·현재 입력 저장을 막습니다. 다른
입력을 불러오면 임시값을 교체하고 그 입력에 맞는 필드만 표시합니다. 같은 예제·
파일·프로젝트를 다시 불러와 저장 입력이 같아도 임시 편집값을 초기화합니다.
원본 JSON을 편집할 때도 폼의 임시값을 초기화합니다. 프로젝트는
현재 설정을 복원하며 과거 기록은 바꾸지 않습니다. 미지원 표본 입력은
JSON 경로를 유지합니다. 기존 실패 행과 불완전
결과의 통계 미계산 규칙도 유지됩니다. 완료된 유한 스윕은 계산한 표본값이며
제조 한계나 연속 구간 전체의 보장이 아닙니다.

## 두 재료 목표 입력하기

**100 Ω differential / 34 Ω common targets**를 불러오면 **Paired material target settings**가
나타납니다. 차동·공통모드 목표와 허용 오차(Ω), 각 변수의 양수 탐색 하한·상한,
그 구간 안의 초기값, 평가 주파수(Hz), 정수 평가 예산(2–128)을 입력합니다.
변수 1·2는 저장된 변수 순서이며 설명에 별칭과 재료 주축을 표시합니다. 두 목표가
요청 메시와 세분 메시에서 모두 통과해야 합니다. 국소 탐색이므로 평가 예산이
해답이나 실행 시간의 상한을 보장하지 않습니다.

`pair-impedance-design/2` 중 동일 재료의 서로 다른 두 상수 주축 유전율 바인딩,
명시한 초기값, 차동·공통모드 목표를 지원합니다. 다른 바인딩이나 생략한 초기값은
JSON 입력을 유지합니다. **Apply settings**는 원본과 수정 문서를 검증한 뒤에만
입력을 교체합니다. 기하·변수 순서·재료 각도와 손실·메시·수정하지 않은 값은
그대로 유지합니다.

임시 편집값을 적용하거나 초기화할 때까지 계산·현재 입력 저장을 막습니다. 입력
복원과 두 목표·단일 목표·스윕 전환은 이전 임시값을 버리고, 숨은 필드는 다른
입력에 영향을 주지 않습니다. 두 목표 탐색 실패의 오류와 완료 이력은 원본 실행
기록에 남습니다. 예산 증가는 새로운 명시적 입력이며 이전 실패를 성공으로 바꾸지
않습니다. 프로젝트는 실패·성공 기록을 각각 보존하고 과거 실행을 열어도 현재
입력 화면은 바뀌지 않습니다.

## 실패한 두 목표 탐색 읽기

정의된 두 목표 탐색 실패는 **Paired impedance targets not accepted**와 함께
요청한 두 목표·허용 오차, 두 탐색 구간, 완료된 모든 평가를 원래 순서로 표시합니다.
각 행에는 두 파라미터·두 임피던스·search/refinement 단계가 있습니다. 예산으로
막힌 평가는 파라미터를 별도로 표시하며, 계산한 임피던스나 추가 완료 횟수를
만들지 않습니다. 수렴 실패와 세분 목표 실패도 기록된 문맥을 보여줄 뿐 이력에서
해답을 선택하지 않습니다.

pair design 스키마 1–2의 기존 `PairImpedanceGoalError` 중 예산·수렴·세분 목표
실패 계약을 지원합니다. 다른 단계·알 수 없는 오류·잘못된 이력은 원본 JSON으로
남습니다. 실패 상태와 수치 기준은 바꾸지 않습니다. 과거 실패를 열어도 현재
입력은 유지하며, 이후 성공한 실행은 실패 표시를 지우지만 실패 기록은 프로젝트
이력과 내보내기에 보존합니다.

## 단일 변수 정규 재료 공차 입력하기

**Single-variable material tolerance**를 불러오거나 단일 상수 유전율·Debye 강도
정규분포 문서를 열면 **Normal material sampling settings**가 나타납니다. 유한한
평균, 양수 표준편차, 표본 수(2–128), 정수 난수 seed(0–4294967295), 평가 주파수(Hz)를
입력합니다. 평균과 표준편차는 무차원이며 음수 평균을 임의로 바꾸지 않습니다.
**Apply settings**는 원본·수정 문서를 검사하고 표본을 계산하거나 걸러내지 않습니다.

`impedance-study/4` 중 재료 변수 하나와 명시한 단일 변수 상관 행렬 `[[1]]`을
지원합니다. 아래의 두 주축 변수는 별도 상관 설정 화면을 사용하고 다른 입력은
JSON 경로를 유지합니다. 기하·재료 모델/pole·
바인딩·물리량·메시·표본 방식·상관 행렬은 그대로이며 임시값 적용/초기화·입력 복원·
과거 기록 조회 동작은 다른 설정 화면과 같습니다.

정규분포는 유한한 구간으로 제한되지 않습니다. 물리적으로 유효하지 않은 표본도
원래 행과 오류를 보존하며 값을 제한하거나 다시 뽑지 않습니다. 불완전 실행은
전체 통계를 만들지 않습니다. seed는 해당 표본 입력을 재현하며 seed 변경은 별도
입력과 실행 기록으로 남습니다. 표본 통계는 제조 한계·최악값·수율 보장이 아닙니다.
내보내기에는 원본 정밀도의 입력·모든 행·실패·완료한 경우의 통계를 유지합니다.

## 주축 재료의 상관 공차 입력하기

**Correlated dielectric study**를 불러오면 **Correlated material sampling settings**에서
저장된 두 상수 주축 유전율의 분포를 편집합니다. 각 변수의 평균과 양수 표준편차,
입력 상관계수(−1~1), 표본 수(2–128), 정수 seed(0–4294967295), 평가 주파수(Hz)를
입력합니다. 설명에 변수 1·2의 저장 별칭과 재료 주축을 표시하며 변수 순서와
바인딩은 바꾸지 않습니다.

같은 재료의 서로 다른 두 상수 주축 바인딩과 명시한 대칭 상관 행렬
`[[1,rho],[rho,1]]`을 지원합니다. 두 비대각 원소를 함께 바꿉니다. 기존 엔진이
허용하는 ±1 경계도 지원하며, 이때 표준화한 표본값은 각각 같거나 부호가 반대입니다.
다른 재료 모델·변수 수·상관 행렬은 JSON 경로를 유지합니다.

이 값은 입력 분포의 상관계수이며 유한 표본이나 임피던스 결과에서 관측되는
상관계수가 아닙니다. 기존 seed 기반 표본 생성기는 바꾸지 않습니다. 두 정규분포는
유한 구간으로 제한되지 않으며 잘못된 행도 다시 뽑지 않고 보존합니다. 불완전 실행은
전체 통계를 만들지 않습니다. 원본·수정 검증, 명시적 적용/초기화, 같은 입력의 복원,
프로젝트 이력은 다른 설정 화면과 동일합니다. 기하·재료 각도/손실·메시·물리량 등
수정하지 않은 설정은 그대로이며 표본 결과에서 제조 한계나 수율 보장을 추정하지 않습니다.

### 다각형 기하 파일

**Open design**에서 `sipi.cross-section/3` 기하도 열 수 있습니다. 직사각형·
테이퍼 도체와 함께 유한한 단순 다각형 도체·국소 다각형 유전체 영역을
표시합니다. 버전 3 입력은 현재 설계를 교체하기 전에 엔진으로 검증합니다.
잘못된 입력이나 표시 복잡도 제한을 넘는 입력은 현재 설계·결과를 유지한 채
거부합니다. 유효한 파일을 열면 이전 결과를 지우고 읽기 전용으로 표시하며,
치수 편집 템플릿을 추정하거나 활성 입력 프로젝트 설계를 교체하지 않습니다.

미리보기는 저장된 꼭짓점을 재표본화하지 않고 표시합니다. 국소 유전체가
기본 층을 덮고 도체가 유전체를 덮는 순서입니다. 영역 이름·상대 유전율·
손실탄젠트는 범례에 표시합니다. 다각형 도체의 치수 표시는 제조 선폭 변수가
아닌 가로 범위입니다. 얇은 층의 이름은 연결선을 따라 읽기 쉬운 위치로
옮길 수 있지만 기하와 메시는 바뀌지 않습니다. 가로·세로 표시 배율이 서로
다른 단면 그림이므로 실측용 도면으로 사용하지 않습니다.

기존 파일 제한 200 KiB 안에서 표시 범위는 층 64개·도체 64개·국소 영역
64개·다각형당 꼭짓점 16384개까지입니다. 더 복잡한 입력은 엔진 제한에 따라
**Saved analysis**를 사용할 수 있습니다. 파일 열기는 계산·수렴 인증·제조
모델의 물리 검증이 아닙니다. 계산을 명시적으로 실행하고 비대칭 쌍은 전체
행렬을 확인하며 메시와 외곽 영역은 별도로 바꾸어 검증하세요. 기하 내보내기는
버전 있는 입력과 좌표를 보존하며 새 기하·재료 스키마를 도입하지 않습니다.

## 법선 두께 코팅 입력 폼

**Normal-film microstrip**과 **Normal-film pair**의 `coating_thickness`는
기판, 도체 윗면, 경사 옆면에 수직인 두께입니다. 평면 코팅의 `coating_height`와
별개입니다. 모서리는 직선 마이터로 만나며 직사각형과 위쪽이 좁아지는 사다리꼴
도체를 지원합니다. 만나는 필름은 하나의 국소 유전체 영역으로 합칩니다.
돌출 윗면, 해상도 미만 틈, 갇힌 공기, 외곽을 벗어나는 코팅은 거부합니다.
둥근 모서리·메니스커스·실제 증착 형상을 추정하지 않습니다. 상부 공기 높이는
가장 높은 코팅 표면 위의 여유 높이입니다.

입력을 바꾼 뒤 **Inspect geometry**를 누르면 메시나 전계 계산 없이 엔진이 만든
실제 다각형 꼭짓점을 검증하고 표시합니다. 입력 수정은 이전 단면 확인을 지우며,
저장 설계를 열면 해당 기하를 복원합니다. 가로·세로 표시 배율은 서로 다르고
외곽이 크면 얇은 필름이 작게 보일 수 있습니다. 그림만으로 메시·외곽 수렴을
판정할 수는 없습니다.

편집 JSON과 입력 프로젝트는 법선 두께, 유전율, 손실 탄젠트, 외곽과 고정 메시를
보존합니다. 두께와 유전율을 함께 공차 샘플링하거나 변화시킬 수 있습니다.
폭 역산은 단일 선로 `z0`, 같은 차동 쌍 `z_diff`를 사용한 뒤 별도 세분 메시로
확인합니다. 법선 코팅 microstrip 자동 역산의 초기 메시만 기본 가장자리 크기의 5배, 원거리 크기의
1/4로 잡고 성장률·최소 각도를 유지합니다. 일반 전방 계산과 사용자가 지정한
메시는 바꾸지 않습니다. 32회 평가·30만 점·5분 제한을 유지하며 세분 단계 실패는 목표 달성이
아닙니다. 기존 준정적 모델을 사용하므로 실제 제조 적합성을 인증하지 않습니다.

관련 검증은 `workbench/tests/test_normal_film_forms.py`,
`tests/sipi/test_conformal_coating.py`, `tests/sipi/test_conformal_resolution.py`,
`node workbench/tests/normal-film.test.mjs`와 실제 native/Worker 흐름
`workbench/tests/normal-film-browser.mjs`입니다. 차동 쌍은 `SIPI_NORMAL_PAIR=1`로
선택합니다. 독립 정전계 기준, 무손실 네트워크 불변식, 기하·JSON 보존과
서로 분리한 메시·외곽 수렴 검사를 포함합니다.

## 법선 코팅 grounded coplanar 폼

**Normal-film grounded coplanar**와 **Normal-film grounded pair**는 기판,
신호선과 양쪽 유한 폭의 직사각형 측면 접지에 같은 법선 두께의 코팅을 적용합니다.
바닥 기준 접지면은 유지하며 신호선만 위쪽이 좁아질 수 있습니다. 차동 입력의
`gap`은 신호 사이 간격, `ground_gap`은 바깥 신호와 측면 접지 사이 간격입니다.
중앙 접지는 없으며 단일 입력의 `gap`은 신호와 접지 사이 간격입니다.

앞 절의 엔진 기하 확인, 정확한 편집 JSON·프로젝트, 코팅 두께/재료 공차와
세분 검증 역산을 공유합니다. 폭 역산은 입력한 접지 폭과 간격을 유지합니다. 자동 역산은
초기 가장자리 크기를 factory의 10배, 원거리 크기를 1/4로 잡고 성장률·최소 각도를
유지합니다. 별도 세분 메시의 수락 기준과 평가 횟수·점 수·시간 제한은 그대로입니다.
법선 두께를 평면 코팅 높이로 바꾸거나 측면 접지를 무한 폭으로 추정하지 않습니다.
메시·외곽을 별도로 점검하며 얇은 코팅의 점 수·시간 제한은 그대로 적용됩니다.
법선 코팅 unbacked coplanar는 아직 기본 편집 폼 없이 Saved analysis로 이용합니다.

검사: `workbench/tests/test_normal_coplanar_forms.py`,
`tests/sipi/test_conformal_coplanar.py`의 독립 영상 전하 패널·복소 P1 조립,
메시/외곽 수렴·정확한 코팅 기하·무손실 회로 불변식을 유지합니다.
`node workbench/tests/normal-coplanar.test.mjs`는 단위와 간격 전달을 확인하고,
`workbench/tests/normal-coplanar-browser.mjs`는 native/Worker 실제 화면을
검사합니다(`SIPI_NORMAL_COPLANAR_PAIR=1`은 차동).
