03

Uniform quasi-TEM line. Constant dielectric properties and a supplied series resistance; skin effect and roughness are not included.

R = 0 selects perfect conductors. Supplied R is a constant diagonal model, including any return contribution you have separately determined. It is not calculated from copper geometry. Save design stores the cross-section only.

Plots and tables cap loss at 300 dB; phase is wrapped to ±180°. Export contains the full complex S values. Port order: near conductors, then far conductors.

Single-ended crosstalk: drive near conductor 1 (port 1); every other port is terminated in the chosen reference impedance. NEXT = S21 (near conductor 2), FEXT = S41 (far conductor 2). Levels are 20 log₁₀ |S|, floored at −300 dB for display. These are separate from differential Sdd21 above.
