# Impedance yield under an explicit sampling model

[한국어](../../locales/ko/pages/packages/sipi/yield.md)

`sipi.yield_assessment` classifies every row of an existing random impedance
study against inclusive limits in ohms. It estimates acceptance probability
under the **specified distribution and numerical model**, not measured factory
yield. Only `uniform` and `normal` studies are accepted. Sweep and corner checks
remain useful deterministic studies, but are not iid yield experiments.

```python
import json
from sipi.study import ImpedanceStudyDocument
from sipi.yield_assessment import ImpedanceYieldDocument
from sipi.execution import normalize_saved, execute_saved

study = ImpedanceStudyDocument("microstrip",
    dict(width=1e-3, substrate_height=.5e-3, thickness=35e-6, eps_r=4.,
         air_height=2e-3, box_width=6e-3), quantity="z0",
    sampling=dict(kind="uniform", count=4, seed=17,
        variables=[dict(name="width", lower=.95e-3, upper=1.05e-3)]),
    mesh=dict(edge_size=20e-6, far_size=.2e-3, grade=.2))
document = ImpedanceYieldDocument(study, minimum=45., maximum=55.,
                                  confidence=.95, minimum_yield=.9)
text = normalize_saved(document.dumps())
report = execute_saved(text, max_evaluations=4)
assert report["result"]["count"] == 4
assert len(report["result"]["rows"]) == 4
json.dumps(report, allow_nan=False)
```

This small sample/mesh example demonstrates the interface, not a production
acceptance study. `document.analyze()` returns `YieldAssessment` with the original
`ImpedanceStudy`; `assess_impedance_yield(study_result, ...)` assesses an already
computed result without solving again. Geometry/material inputs and all errors
are retained. Supplying a manually constructed result is not proof that it was
generated by the declared distribution or solver.

## Counts, failures and confidence

Let N be all planned trials, P the number inside both limits, F the number
outside and U the unresolved solver/geometry rows: `N=P+F+U`. No failed row is
dropped, resampled or assigned a fabricated impedance. The observed acceptance
fraction is bounded by `[P/N, (P+U)/N]`; it becomes a single value only if U=0.
Invalid geometry and solver errors are both unresolved here. If manufacturability
itself is a rejection criterion, define that explicitly in a separate model.

For central confidence c, each tail is `(1-c)/2`. We report the envelope of
equal-tailed **Clopper–Pearson exact binomial intervals** over every possible
assignment of the U unresolved labels. Its lower endpoint is the interval's
lower endpoint for P successes in N trials; its upper endpoint uses P+U
successes. Zero-success lower and all-success upper endpoints are exactly 0
and 1. For example, 100/100 passes at 95% confidence has a lower bound near
0.9638; an observed 100% is not proof of population yield 100%.

These are fixed-sample, pointwise intervals. Normal-variable correlation within
one row is allowed; rows must be independently drawn from the same specified
distribution. The interval's nominal coverage is over repeated such studies,
not a probability that this realized interval contains a fixed true yield.
It does not include mesh error, material-fit error, uncertain distribution
parameters, sample-selection bias or stopping after inspecting results. Searching
many designs and choosing one also needs multiple-comparison control; this
single-design API does not supply that control.

`minimum_yield` is optional and lies in [0,1]. Its `goal_status` is:

- `pass` when the confidence lower bound is at least the target;
- `fail` when the upper bound is below the target;
- `undetermined` otherwise; `not-requested` when the target is null.

The default confidence is .95, strictly between 0 and 1 at representable float
precision. Limits are finite nonnegative numbers or null, at least one is
required, and `minimum <= maximum`. Equality is accepted without hidden slack.

## Saved contract and execution

`sipi.impedance-yield/1` has exactly `schema`, `study`, `minimum`, `maximum`,
`confidence` and `minimum_yield`. `study` is an existing strict impedance-study
version 1–4, including geometry/material-variable bindings and the original
seed/count/correlation. Unknown versions/keys, duplicate JSON keys, nonfinite
numbers and inconsistent/subset/reordered result rows are rejected. Parsing
does not solve fields. Inputs and exported dictionaries are detached snapshots.

`execute_saved` applies its evaluation budget to the entire nested study before
field work. Output preserves quantity, ohm limits, sampling model, P/F/U, sample
fraction bounds, confidence bounds, goal status and every row's value/parameters,
geometry, material evaluation and error. `status="incomplete"` means U>0;
`status="complete"` means all calculations finished, regardless of whether the
yield target passed. The interval method and stated-distribution scope are
explicit labels. It never converts incomplete calculations to an optimistic yield.

Tests compare small-N bounds with independent finite binomial sums and bisection
at `1e-12`, and with SciPy's exact binomial interval API. They check endpoints,
symmetry, confidence/sample-count behavior, unresolved envelopes, strict JSON,
budgets and actual FEM-study replay. Existing field/mesh acceptance criteria
remain unchanged. This adds no runtime dependency or new physical accuracy claim.
