# 분리 검증

기준은 fieldalgo/openphysics b8f7c0427b75362ed5e8298bc81682e7076abe4e입니다.
수치 소스·시험·실행 예제 60파일은 provenance.json에 기록한 원본 SHA-256과 같습니다.
전체 원본 커밋 이력은 상류에 유지하며 새 저장소는 출처를 기록한 스냅샷으로 시작합니다.

Linux / CPython 3.12.14에서 SIPI와 별도 galerkin/meshine 휠의 전체 회귀·설치본
소비자 시험 598개가 377.73초에 통과했습니다. simcase 기하 계약 18개도 통과했습니다.
체크아웃 밖에서 별도로 실행한 25개는 설치본 소비자 7개와 같은 기하 계약 18개로,
위 집계와 중복됩니다. sdist에서 재생성한 휠의 모든 내용은 직접 만든 휠과 바이트 단위로 같습니다.

자체 패키지는 고정 스냅샷으로 새로 빌드·설치했습니다. 외부 연결 불가로 third-party는
기존 환경의 설치본을 재사용했고 온라인 의존 해석은 검증하지 않았습니다. NumPy 2.5.4,
SciPy 1.18.1, Shapely 2.2.0, scikit-rf 2.2.0을 사용했습니다. macOS/Windows·새 원격 CI는
실행 전이며 Windows EXE와 웹 소비자 전환도 이번 결과에 포함되지 않습니다.
