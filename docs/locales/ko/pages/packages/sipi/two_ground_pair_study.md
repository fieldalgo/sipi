# 두 접지면 쌍 제조 공차 연구

[English](../../../../../packages/sipi/two_ground_pair_study.md)

`TwoGroundForwardPairStudyDocument`는 엄격한
`sipi.two-ground-forward-pair-study/1` 입력을 저장합니다. study/3 또는 /4의
기하·재료 표본을 명시적인 두 접지면 선로 계산에 연결합니다. 한 번의 추출로
Ic=0, Id=0의 별도 여기 조건에서 차동·공통 순방향 특성 임피던스 대각 성분의
실수부를 얻습니다. 독립 전파 모드의 임피던스를 뜻하지 않습니다.

영문 예제는 장 계산 없이 네 모서리 표본의 입력만 준비합니다.
`study.analyze(max_evaluations=4)` 또는 저장 실행 API로 계산합니다.
길이는 m, 주파수는 Hz입니다. 신호 도체 각각과 위·아래 접지면의 금속 법칙은
표본 사이에서 고정됩니다. 저장 JSON은 모든 패널 제어값을 요구하며 누락·중복·
알 수 없는 필드와 비유한 수를 거부합니다. 명목 입력 검사는 모든 표본의 유효성을
보장하지 않습니다. 평가 예산은 장 계산 전에 확인합니다.

기존 순서 보존 샘플러의 모서리, 스윕, 시드 지정 균등·정규 표본과 재료 바인딩,
상관 및 고정 기하 제약을 그대로 사용합니다. 실패한 표본도 잘라내거나 삭제·
재추출하지 않으며 같은 값의 중복 표본도 각각 계산합니다. 각 행에는 원래 표본,
해석된 기하·재료, 선로 입력, 두 결과 또는 실패 단계·원인을 남깁니다.
추출 후 진단 실패에도 이미 계산한 전류·메시 근거를 보존합니다. 중단 요청은
전파하고 일반 오류 뒤에는 다음 행을 진행합니다. 모든 행이 성공해야 통계를
제공합니다. 일부 실패한 실행은 `incomplete`이며 요청·기록·프로젝트를 다시
열어도 계산하지 않습니다. 기술 통계는 생산 수율이나 신뢰구간의 주장이 아닙니다.

등록된 물리 검사는 2 GHz의 선폭·간격 네 조합에서 변당 64·128·256 패널을
사용합니다. 인접 단계 각각의 R·L·C0 변화는 절대 허용오차 0, 상대 0.01 이하여야
합니다. 각 단계에서 복소 RLGC로 순방향 임피던스를 독립 재구성합니다.
이는 명시한 유한 영역 검사이며 외곽 수렴·실측 정확도·모든 단면이나 주파수의
검증이 아닙니다. 기존 시험 기준은 그대로 둡니다.

`dependencies.json`의 정확한 공유 리비전이 제공하는 `galerkin.laplace_two_ground`가
필요합니다. 기능이 없으면 명시적으로 실패하며 다른 전류 계산법을
대신 사용하지 않습니다. 브라우저·macOS·Windows 검증은 Linux 검사와 별개입니다.

균등·정규 iid 표본의 [동시 규격 평가](two_ground_pair_yield.md)는 실패 행도
확률 구간의 분모에 보존합니다.

[유한 주파수 연구](two_ground_sampled_pair_study.md)는 같은 제조 표본을 전체 명시
주파수에 유지하며 실패한 행을 통째로 보존합니다.
