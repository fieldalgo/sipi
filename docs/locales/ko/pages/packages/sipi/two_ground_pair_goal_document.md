# 양면 접지 선로의 저장된 쌍 임피던스 목표

[English](../../../../../packages/sipi/two_ground_pair_goal_document.md)

`TwoGroundForwardPairDesignDocument`는 엄격한
`sipi.two-ground-forward-pair-design/1` 입력을 저장하고
[기존 유계 쌍 역산](two_ground_pair_goal.md)을 실행합니다. 전체 복소 혼합 좌표
특성 임피던스의 두 실수 대각값을 각각 Ic=0, Id=0 조건에서 목표로 삼습니다.
서로 독립된 전파 모드의 임피던스로 바꾸지 않습니다.

영문 예제는 장 계산 없이 입력을 생성·저장·다시 읽습니다. 예제 목표의 달성 가능성을
보장하지 않습니다. 길이는 m, 주파수는 Hz, 목표와 절대 허용치는 Ω입니다.
study/3 또는 /4의 순서 있는 기하·재료 변수, 고정 피치와 전체 평면 간격 제약을
보존합니다. 두 변수는 양수이며 서로 다른 상·하한을 갖는 corners 입력이어야 합니다.
신호와 위·아래 접지면은 각각 고정된 전체 표면 금속 법칙을 선택합니다. 완전 도체로
조용히 대체하지 않습니다.

기본 입력, 초기점(없으면 중점), 네 모서리와 각 volume-only/panel-only/joint 세분
입력을 장 계산 전에 확인합니다. 저장 JSON의 누락·미지·중복·비유한 필드는
거부하며 패널 설정은 세 필드 모두 명시해야 합니다. 이 사전 검사가 범위 내부의
모든 기하나 물리 정확도를 보장하지 않습니다. 기존 4..10000 평가 예산에는 실패한
풀이와 최적화 탐색도 포함되고 세 평가는 세분에 예약합니다. 원 절대 목표와
상대 0.005 세분 기준은 유지합니다.

`design.solve()`와 `execute_saved(design.dumps())`는 같은 직접 역산을 사용합니다.
실행 기록은 선택 기하·탐색 이력·세 세분 입력·접지면별 전류 근거·유전체 메시
식별자를 보존합니다. 실패하면 원 `TwoGroundPanelLineError` 상세와 완료된 시도가
남고 인터럽트는 전파됩니다. 요청·결과 기록·프로젝트는 재계산 없이 다시 읽습니다.
콜백이나 자동 재시도를 저장하지 않습니다.

공유 `galerkin.laplace_two_ground`는 `dependencies.json`의 정확한 리비전에서 제공합니다.
기존 추출 기본값은 유지하며 해당 기능이 없으면 대체 계산 없이 실패 기록을
반환합니다. 유한 영역 세분은 외곽 수렴·실측 정확도·생산 수율·브라우저/Windows 지원
인증이 아닙니다. 기존 schema는 바꾸지 않습니다.

[요청 안에서 동일 전류 계수를 재사용](two_ground_current_reuse.md)하며 선로 시도 수와 수치 기준은 유지합니다.
