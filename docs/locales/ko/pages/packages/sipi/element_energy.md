# 정전계 추출의 요소 에너지

`capacitance_matrix`는 같은 galerkin P1 강성 행렬, Dirichlet 해, 도체 순서와
재료 계수를 사용합니다. Maxwell 정전용량은 동등한 요소 적분으로 계산합니다.

`C_ij = epsilon_0 sum_T area_T grad(V_i)^T eps_T grad(V_j)`

기울기는 galerkin의 공개 `element_gradient`로 구하고, 실수부와 허수부 기여를
각각 `math.fsum`으로 합산합니다. 조립된 `V.T @ K @ V`에서 대각·비대각 항끼리
상쇄되는 연산을 피합니다. 메시나 유한요소 근사는 바꾸지 않고 추출 과정의
부동소수점 산술만 바꿉니다. 상호성을 명시적으로 유지하며 복소 쌍선형 형식은
어느 필드에도 켤레를 취하지 않습니다. 켤레를 사용하면 손실 정전용량 문제가 달라집니다.

스칼라·요소별·횡방향 텐서 계수의 검증과 단위는 그대로입니다. 공개 인자,
JSON 입력, 진공 추출, 손실 부호와 목표 역산 허용오차도 유지합니다. 결과의
끝자리는 달라질 수 있으므로 수치 결과에 정확한 엔진 배포물 식별자를 남기세요.
메시와 외곽 경계 수렴은 별도로 확인해야 합니다.

독립 검사는 균일·두 영역 직사각형의 세 affine 필드를 스칼라·텐서 계수로
적분합니다. 쌍선형 에너지와 Hermitian 에너지를 구별하는 복소 필드도 포함합니다.
해석 적분과 상대 `1e-13` 이내로 일치하고 삼각형 순서를 바꿔도 결과가 정확히
같아야 합니다. 평행판 여섯 사례는 `epsilon_0*width*eps/height`와 상대 `1e-10`
이내로 비교합니다. 기존 해석해·독립 FEM·재료·비대칭 선로·임피던스 역산
검사의 허용오차는 유지합니다. 이 검사는 제한된 수치 문제의 검증이며 모든
플랫폼에서의 동일 산술이나 수렴하지 않은 기하의 물리 정확도를 보장하지 않습니다.
