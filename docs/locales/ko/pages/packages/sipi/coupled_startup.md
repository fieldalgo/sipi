# 두 신호 유한 RLGC 시작 응답 회로

`coupled_rlgc_ladder_response`는 초기 저장 에너지가 없는 균일한 **두 신호 유한
회로**를 계산합니다. 상수 행렬의 상호 인덕턴스·커패시턴스·직렬 저항·병렬
컨덕턴스를 유지합니다. 도체 수나 종단 종류를 자동 확장하지 않습니다.

```python
import numpy as np
from sipi import coupled_rlgc_ladder_response

t = np.linspace(0., 12e-9, 121)
drive = np.column_stack((np.minimum(t/2e-9, 1.), np.zeros(len(t))))
r = coupled_rlgc_ladder_response(t, drive,
    R=[[20., 3.], [3., 20.]], L=np.array([[500., 100.], [100., 500.]])*1e-9,
    G=[[.002, -.0003], [-.0003, .002]],
    C=np.array([[220., -40.], [-40., 220.]])*1e-12,
    length=.1, cells=32, source_resistance=[25., 25.], load_resistance=[100., 100.])
assert r.voltage.shape == (121, 4) and r.node_voltage.shape == (121, 33, 2)
assert r.port_names == ('near_0', 'near_1', 'far_0', 'far_1')
assert r.power_balance_relative_error <= 1e-10 and np.all(r.energy >= 0)
record = r.to_dict(include_states=True)
assert record['scope'] == 'finite-passive-two-signal-rlgc-ladder-startup'
```

## 수동 입력과 상한

R [ohm/m], L [H/m], G [S/m], C [F/m]는 정확히 대칭인 유한 실수 2x2 행렬입니다.
R/G는 양의 준정부호여야 하며 정규화 고유값이 음수면 clamp나 수동성 보정 없이
거부합니다. L/C는 양의 정부호이고 정규화 최소/최대 고유값 비가 엄격히 1e-12보다
커야 합니다. 이는 수치 적용 조건이며 재료 정확도 주장이 아닙니다. 거의 대칭인
행렬을 자동 대칭화하지 않습니다. 0인 R/G와 rank-one 준정부호 손실은 허용합니다.

길이 [m]는 유한 양수, `cells`는 명시적 1..128 정수입니다. 시간은 0에서 시작하는
2..10000개 유한 실수로 엄격히 증가하며 상대 1e-10, 절대 0 허용 범위에서 균일
간격입니다. 입력은 `(표본 수,2)` 유한 실수이며 첫 행은 0입니다. 선형 보간하고
마지막 행을 유지합니다. bool은 거부합니다. 소스와 부하 저항은 각각 **양수**인
유한 옴 단위 값 2개를 명시합니다. 대각 외부 종단이며 스칼라 확장, 0, null,
무한대는 허용하지 않습니다. 이상 소스, 개방/단락/리액티브 종단은 이 API 밖입니다.

각 dx 구간에 전체 R*dx/L*dx 행렬을, 노드에 G*dx/C*dx를 사용하며 양 끝은 절반
가중치입니다. 기존 SciPy `lsim`으로 PWL 상태공간 회로를 전파하며 새 Maxwell
FDTD 솔버가 아닙니다. 셀 행렬·기울기·계수·상태·에너지 진단이 표현 범위를 벗어나면
오류입니다. 상한은 정확도·실행 시간·메모리 보장이 아니며 입력별 공간·소스 대역·
시간 격자 수렴을 확인해야 합니다.

## 포트·상태·에너지

`voltage`, `current`는 near_0, near_1, far_0, far_1 순서의 4열입니다. 모든
포트 전류는 선로 안을 향합니다. `node_voltage`는 `(표본 수,cells+1,2)`,
`segment_current`는 `(표본 수,cells,2)`이며 전류는 near에서 far 방향입니다.
단일 회로의 읽기 전용 복사 배열, 단위 포함 독립 `inputs`, 선택적인
`to_dict(include_states=True)` 직렬화를 재사용합니다. scope와 포트 이름은
두 신호 회로를 명시합니다. 기본 JSON은 내부 상태를 제외하며 버전 저장 입력이
아닌 결과입니다.

에너지/전력 기록은 두 도체 합계이고 개별 포트 전력은 V*I입니다. 에너지는
상호 항까지 포함한 전체 이차형식입니다. 검증된 PSD/SPD 고유기저의 제곱합으로
저장 에너지와 R/G 손실을 계산하여 거의 같은 항의 차감을 피하며 음의 고유값을
자르지 않습니다. `energy_rate`는 회로 우변에서 계산합니다. E_dot - line_power +
series_loss + shunt_loss 잔차를 에너지율·포트입력·전체손실 중 가장 큰 크기로
정규화한 값은 1e-10 이하여야 합니다. 정확한 0 응답은 상대 잔차도 0입니다.
에너지와 내부 손실은 비음수이고 소스/종단 저항 손실은 별도입니다. 음의 귀환
포트 전력을 보존합니다. 이 대수적 균형만으로 연속 선로 수렴을 증명하지 않습니다.

## 독립 수락 기준

예제 행렬·길이에서 첫 도체를 0..2 ns에 1 V까지 올리고 둘째는 0으로 유지하며
0..12 ns의 1201표본을 비교합니다. R=G=0이면 직교 공통/차동 모드로 분리할 수
있습니다. 각 모드의 정확 무손실 지연 해를 물리 도체 좌표로 복원하면 32/64/128셀
최대 전압 오차는 .004970/.002842/.001908 V, 전류 오차는
.000073341/.000028412/.000019071 A입니다. 모두 감소하고 128셀에서 .02 V/.0005 A
이하입니다. 상호 결합과 유한 공간 분산을 검사합니다.

전체 유손실 행렬에서는 독립 scikit-rf 2.2.0의 500 MHz 모드별 분포 선로 ABCD를
물리 좌표로 복원합니다. 정현파 20주기, 주기당 256표본, 끝 중복점 제외 마지막
4주기 phasor를 비교하면 32/64/128셀 오차 .000897/.000227/.0000681 V로 감소하고
1e-3 V 이하입니다. PWL 보간 오차를 포함합니다. 이 모드 대조는 교환 대칭에
의존하며 임의 행렬의 모드 분해를 주장하지 않습니다.

별도 KCL/인덕터 방정식의 DOP853 적분으로 비대칭 정부호/준정부호 행렬과 서로
다른 저항 종단의 16셀을 검사합니다. 최대 전압 차이는 1e-8 V 이하이며 rtol1e-10,
atol1e-12, 최대 간격은 최소 모드 지연/(5*cells)입니다. 같은 유한 회로의 전파
알고리즘 비교이며 독립 공간 이산화가 아닙니다. SciPy 1.18.1은 기존 BSD-3-Clause
실행 의존성, scikit-rf 2.2.0은 BSD-3-Clause 시험 전용 기준이며 새 의존성은 없습니다.

결합 0은 서로 다른 두 단일 회로로 환원됩니다. 정확 저항 DC 한계, 도체 순열,
중첩, 시간/임피던스 스케일, rank-one 손실, 0 입력, 펄스 귀환 에너지, 복사와
엄격 입력도 검사합니다. 기존 단일 회로 및 저장 검사는 유지합니다. 실제 기판
재료 정확도, 임의 분산, 일반 TDR/eye/BER, 브라우저/Windows 지원 검증은 아닙니다.
