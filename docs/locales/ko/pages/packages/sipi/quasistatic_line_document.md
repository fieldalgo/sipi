# 준정적 주파수 해석 입력 저장

`QuasistaticLineDocument`는 명시 기하 또는 편집 가능한 단면과 주파수 계산
조건을 함께 저장합니다. 기존 준정적 전계·네트워크 엔진을 사용합니다.
로드는 메시나 해석을 실행하지 않고, `analyze()`는 단면을 한 번 추출해
`line`, `network`, canonical `input_json`을 반환합니다. 파일은 쓰지 않습니다.
사용 예제는 [영문 문서](../../../../../packages/sipi/quasistatic_line_document.md)를 참고하세요.

`sipi.quasistatic-line/1`의 필드는 정확히 `schema`, `section`,
`frequency_hz`, `resistance_ohm_per_m`, `length_m`, `reference_ohms`입니다.
`section`은 기존 cross-section 또는 template-section 문서입니다. 편집 입력은
파라미터·정확한 기하·해결된 메시 설정을 보존하고 명시 기하는 그대로 보존합니다.
주파수는 비어 있지 않은 유한·비음수·엄격 증가 Hz 배열입니다. 저항과 길이는
유한·비음수 ohm/m 및 m 스칼라, 기준 임피던스는 유한·양수 ohm 스칼라입니다.
누락·추가 필드, 중복 키, 미지원 버전, 수치 필드의 불리언·비유한 값을 거부합니다.
반환한 사전을 수정해도 원본 입력은 바뀌지 않습니다.

저항은 사용자가 **직접 제공한** 신호별 동일 대각값이며, 의도한 귀환 기여도
별도로 포함해야 합니다. 추출된 C/L 및 일정 손실탄젠트의 G(f)를 사용합니다.
구리 저항·표피 효과·거칠기·내부 인덕턴스·재료 분산을 추정하지 않습니다.
그 모델에는 별도 transmission-line 재료·금속 계약을 사용하세요.
주파수 입력 수락은 준TEM 유효성이나 정확도 인증이 아닙니다. 메시·외곽 수렴을
별도로 검사해야 합니다.

공통 실행은 C·C0·C_loss·L과 근단 신호 다음 원단 신호 순서의 전체 복소
single-ended 네트워크를 반환합니다. 비대칭 쌍의 결합도 보존합니다.
주파수 의존 transmission-line 문서의 추가 진단 옵션은 여기서 받지 않습니다.

독립 V/I 경계식과 행렬지수, DC 직렬 저항·길이 0 through 극한, 상반성·수동성,
직접/저장 행렬의 정확한 일치와 전계 1회 추출을 검증합니다. 이는 저장·전파 계약의
검증이며 제조 실측 정확도 검증이 아닙니다.
