# 한 변수의 양면 접지 선로 목표 역산

[English](../../../../../packages/sipi/two_ground_line_goal.md)

`sipi.two_ground_line_goal`의 `seek_two_ground_line_quantity`는 양수 변수 하나를
이분법으로 찾습니다. `impedance_real`(Re(Zc), Ω), `attenuation`(Re(gamma), Np/m),
`differential_forward_impedance_real` 또는 `common_forward_impedance_real`
(Re(Zdd)/Re(Zcc), Ω)을 고릅니다. 쌍은 Ic=0/Id=0의 별도 여기에서 전체 특성 행렬을
사용하며 독립 모드나 유한 단자 임피던스가 아닙니다.

영문 예제는 factory를 정의·검증하며 탐색을 실행하지 않습니다. factory는 양수 주파수
하나·길이0·단선1개 또는 순서 있는 신호2개의 명시적인 양면 접지 선로를 반환해야
합니다. 양 끝점이 모두 계산되어야 합니다. 끝점이 원 절대 오차 이내이면 선택할 수
있으며 그렇지 않으면 끝점 잔차의 부호가 달라야 합니다. 이분법은 연속성·단조성·
유일성·전역 최적점을 증명하지 않습니다. 이 API는 factory를 저장하지 않습니다.

주파수·신호 순서·모든 전류 패널 제어값은 고정합니다. 각 탐색 장 계산 전에 세 세분
입력을 모두 검사합니다. 5..10000 시도 중 세 번을 joint·volume-only·panel-only에
예약합니다. 기존 한 변수 탐색 루프 밖에 두 시도를 남기고, 그 루프의 마지막 세분이
joint가 됩니다. 그 뒤 체적만·패널만 계산합니다. 이 실제 순서를 이력에 남깁니다.
예산이 내부 행렬 연산 횟수·시간·메모리를 별도로 제한하지는 않습니다.

선택한 입력을 동결하고 세분 중 factory를 다시 부르지 않습니다. 체적축은 해석된
edge/far/grade를 절반, 패널축은 변당 패널을 두 배로 하며 joint는 둘 다 바꿉니다.
접지 모드·보간 차수·금속·재료·치수·경계는 그대로입니다. 두 배 패널도 기존 자원
제한 안에 들어야 합니다. 모든 세분은 원 절대 목표를 만족해야 하고 명목 대비 각각,
joint 대 각 단일축의 상대 변화가 모두0.005 이하여야 합니다. 비교 이전 값이 분모이며
0에 대해서는 결과0만 허용합니다. 평균·재시도·대체 계산·오차 완화로 실패를 수락하지
않습니다.

결과는 선택 선로·joint 결과·세 세분 입력과 값·전류/메시 근거·전체 이력을 보존합니다.
실패한 factory·장·진단도 시도에 셉니다. `TwoGroundLineQuantityGoalError.to_dict()`는
시도 수·단계·실패 변수/입력·원래 형식화된 선로 원인·완성된 장을 남깁니다. 중단은
전파합니다. 성공한 제한 탐색을 외곽 적합성·실측 정확도·플랫폼 인증으로 보지 않습니다.

등록 물리 조건은 예제의2GHz 편심 단선, 선폭 .55–.65mm, 목표58Ω±.05Ω,
64→128 패널,40시도입니다. 선택/세분 장을 복소 sqrt(Z/Y), sqrt(ZY)로 독립 비교합니다.
제어 검사는 단선·쌍 근, 동결 세분축, 모든 실패 단계, 예약 예산,0감쇠와joint 대 단일축
수렴을 다룹니다. 기존 단선/FEM/corner 역산 회귀와 정확한 소스·설치 산출물은 별도
검증으로 유지합니다.

[저장 설계](two_ground_line_goal_document.md)로 템플릿·기하/재료 바인딩·목표·예산을
공통 실행 API에 보존할 수 있습니다.
