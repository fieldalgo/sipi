# 한 쌍 역산 요청 안에서 같은 두 접지면 전류 재사용

[English](../../../../../packages/sipi/two_ground_current_reuse.md)

단일 주파수·유한 주파수의 두 접지면 쌍 역산은 요청 한 번 안에서만 성공한 진공
전류 계수를 재사용합니다. 명목·체적 전용 평가는 전류 입력이 같고, 패널 전용·
동시 세분 평가도 전류 입력이 같습니다. 각 선로 시도는 원래의 입력 승인, 금속
손실, 유전체 추출과 수치 검사를 그대로 수행합니다. 네 시도와 이력을 모두
보존하며 같은 전류 해상도의 반복을 별도 해상도 검증으로 세지 않습니다.

요청의 내부 범위에 최근 사용한 불변 결과를 최대 여덟 개만 유지합니다. 정확한
솔버 함수 정체성, 직사각 영역 크기, 순서 있는 다각형 binary64 바이트, 도체
이름·접지 역할, 패널 수·접지 모드·보간 차수가 모두 키에 들어갑니다. 진공
전류 풀이의 입력이 아닌 유전체 정보·주파수·표면 금속·체적 메시 설정만 제외하며
각 항목의 원래 검증과 계산은 유지합니다.

캐시가 있어도 단면·전류 설정·솔버 기능 검사를 생략하지 않으며 금속·skin-depth
승인은 전류 추출보다 먼저 수행합니다. 실패 결과는 저장하지 않습니다. 중첩
역산은 범위가 분리되며 예외·사용자 중단 시 결과를 비우고 바깥 범위를 복원합니다.
역산 밖의 직접 전류·선로 호출은 기존대로 매번 계산합니다. 공유 솔버·수치
허용값·기하·JSON 스키마·탐색 예산·세분 조건·외곽 조건은 바꾸지 않습니다.

키의 각 요소, 제외하는 정보, 함수 수명, 저장 개수와 퇴출, 실패 재시도, 성공 후
부적합 입력 거부, 중첩·동시 요청 격리와 중단 정리를 검사합니다. 등록한 선택
기하의 단일 주파수·유한 주파수 사례에서는 재사용 전후의 전체 결과, 이력,
전류/메시 관측이 정확히 같은지 비교합니다. 네 선로 시도에서 전류 풀이를 네
번에서 두 번으로 줄이는 것이 목표이며 이를 실행 시간 배수로 표현하지 않습니다.
소스·설치 산출물·브라우저 근거는 정확한 버전별로 별도 기록합니다.

물리 계약과 한계는 [단일 주파수 역산](two_ground_pair_goal_document.md)과
[유한 주파수 역산](two_ground_sampled_pair_goal_document.md)을 참조합니다. 재사용으로
절대 정확도를 인증하거나 독립 패널·체적·외곽·실측 검증을 대신하지 않습니다.

같은 역산 요청 안에서만 성공한 동일 메시를 재사용합니다. 복사본 격리와 자원 한도는 [메시 재사용](two_ground_mesh_reuse.md)을 참고하세요.
