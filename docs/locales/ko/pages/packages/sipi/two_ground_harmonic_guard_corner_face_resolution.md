# 두 활성 도체와 고정 전위 가드의 유한 해상도 비교

`sipi.two_ground_harmonic_guard_corner_face_resolution`의
`assess_two_ground_harmonic_guard_corner_face_line_resolution`에
[고정 전위 가드 선로 입력](two_ground_harmonic_guard_corner_face_panel_line.md)을
전달합니다. 두 물리 접지면 사이의 활성 Trace 두 개와 고정 전위 가드 하나에
대해 전류 밀도와 유전체 메시의 세분 영향을 따로 비교합니다. 직접 호출하는
Python 기능이며, 평가용 저장 스키마를 추가하거나 기존 입력의 계산법을
바꾸지 않습니다.

세 가지 `refined_panel_options`와 명시적인 `outer_documents`가 필요합니다.
등록한 검증은 전류 분할 32→48, 접지 모드 256→512, 유전체 edge/far/grade
각각 0.5배를 사용합니다. 외곽 입력의 폭은 16/32 mm, 접지 모드는
1024/2048이며 나머지 메시와 전류 해상도는 동시 세분 조건을 유지합니다.
도체 형상, 물리 접지면 위치, 재료, 주파수, 길이, 포트는 바꿀 수 없습니다.
입력과 계산 예산을 모두 확인한 뒤에만 장을 풉니다. 공유 엔진의 물리 패널
512개와 밀도 미지수 1024개 제한은 유지합니다.

외곽 입력이 두 개이면 기준·유전체만·전류만·동시 세분·외곽 두 개의
여섯 선로를 계산합니다. 단독 세분은 기준과, 동시 세분은 두 단독 세분과,
각 외곽은 동시 세분과 비교합니다. 선택한 R, 내부 L, 외부 L, C, G, 진공 C0의
각 행렬 원소에 절대 허용량과 상대 허용량×두 값의 큰 크기를 더해 적용합니다.
작은 상호 항을 숨기는 분모 하한은 없습니다. 유한 조건 간 일치는 절대 정확도나
점근 수렴을 뜻하지 않습니다.

정확한 JSON 입력, 실제 유전체 메시와 전류 계산 기록, 완료한 비교를 보존합니다.
전류·메시·유전체·네트워크 단계의 형식화된 실패는 이전 결과를 남기고 이후
계산을 중단합니다. 계산은 끝났어도 불일치하면 수용되지 않습니다. 사용자 중단은
실패 결과로 바꾸지 않습니다.

전류와 메시 재사용은 이 호출 안에 한정합니다. 여섯 선로 평가는 그대로 예산에
계수하며, 기준/유전체와 전류/동시 세분의 정확히 같은 장은 재사용하므로 서로
다른 전류장은 네 번 풉니다. 각 평가의 물리·재료 입력 검사는 계속 실행하고,
근사 형상 키나 요청 사이의 캐시를 쓰지 않습니다.

검증 범위는 등록한 비균일 유전체·테이퍼 세 도체 형상 한 개의 1/3/10 GHz이며,
여섯 계산량 모두 상대 1%, 절대 0 기준을 적용합니다. 원소별 차이의 독립 재계산,
실패 보존, 가드 지정·금속 법칙 유지, 장 계산 전 입력 거부도 확인합니다. 부유 도체, 다른 형상,
실측 정확도, 브라우저 실행, 다른 운영체제의 검증을 뜻하지 않습니다.
