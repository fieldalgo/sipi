# 선형 모서리 전류의 명시적 유한 해상도 비교

`sipi.two_ground_linear_corner_face_resolution`의
`assess_two_ground_linear_corner_face_line_resolution`은 저장된
`TwoGroundLinearCornerFacePanelTransmissionLineDocument`를 대상으로 전류 밀도와
유전체 메시를 별도 축으로 세분화합니다. 기존 저장 스키마의 방법은 바뀌지 않습니다.

`refined_panel_options` 세 항목과 하나 이상의 `outer_documents`를 명시합니다.
물리 도체·접지 위치·재료·주파수·길이·포트는 같아야 하며 측면 폭만 넓힐 수 있습니다.
외곽 입력은 함께 세분화한 메시와 전류 설정을 유지하고 접지 모드 수만 늘릴 수 있습니다.
전체 입력과 계산 횟수 한도는 장 계산 전에 검사합니다. 물리 패널512개·밀도 미지수1024개
한도를 유지하며 유한 Trace 한 개와 두 개 모두32→64분할이 이 한도에 들어갑니다.

외곽 두 개일 때 단계는 기준, 체적만, 전류만, 동시 세분화, 외곽0, 외곽1입니다.
각 단일 축은 기준과, 동시 세분화는 각 단일 축과, 각 외곽은 동시 세분화와 비교합니다.
선택한 R·내부 L·외부 L·C·G·진공 C0의 각 성분에 사용자가 준 절대 허용치와
상대 허용치×두 값의 최대 크기를 적용합니다. 분모 하한을 넣지 않습니다.
유한 단계 간 일치는 점근 수렴이나 절대 정확도를 뜻하지 않습니다.

결과에는 정확한 입력 JSON, 실제 유전체 메시, 전류 계산 기록과 완료된 비교가 남습니다.
전류·메시·유전체·회로의 형식 있는 실패는 이전 결과를 보존하고 이후 계산을 멈춥니다.
계산이 끝나도 불일치하면 미승인 상태이며 사용자 중단은 전파됩니다.

실제 다층 단일·쌍 선로에 기존 상대1%·절대0 기준을 유지하고 성분별 비교, 계산 전
거부, 실패 보존과 중단 전파를 검사합니다. 고정 접지 도체, 임의 도체 수, 실측 정확도,
브라우저 실행이나 다른 운영체제 지원을 입증하지 않습니다.

작업 내부에서 최대8개 전류 결과와 한도 있는 메시 사본을 재사용합니다. 선로 평가6회는 여전히 예산6회이며, 같은 진공 기하·설정의 전류 장은 외곽 두 개를 포함해4회 계산합니다. 모든 호출의 물리·재료 검사를 유지하고 작업 종료 시 보관값을 지웁니다. 근사 기하 키를 사용하지 않습니다. [저장 입력](two_ground_linear_corner_face_resolution_document.md)을 참고하세요.
