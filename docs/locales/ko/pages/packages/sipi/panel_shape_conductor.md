# 정전용량 형상미분으로 적분 표면전류 계산

`panel_shape_current_factors`는 유한 두께의 볼록 도체와 하부 접지면에서
명시적으로 선택하는 계산법입니다. 진공 전기 쌍대 문제의 옆·윗벽은 절연입니다.
기존 공유 경계 솔버를 호출하며 기존 gradient·dual-cell·panel-current 기본값이나
저장 선로 스키마를 바꾸지 않습니다.

도체 하나를 각 면의 안쪽 법선으로 h만큼 축소하면
`Q_b = -d(C/epsilon)/dh`로 그 경계의 전류 적분 행렬을 구합니다. 하부 접지면은
바깥으로 움직여 별도 계산합니다. 원래 정전용량 행렬로 단위 신호 전류에 맞추고,
명시 접지 도체의 전위는 0으로 유지합니다. 접지 도체들과 하부 평면의 기여를
reference로 합칩니다. 유전체 재료 메타데이터는 이 진공 계산에 들어가지 않습니다.

같은 패널 설정에서 중앙차분 h와 h/2를 계산합니다.
`h = step_fraction * 가장 짧은 도체 면 길이`이며 기본 비율은 1e-3,
허용 범위는 1e-5~1e-2입니다. 모서리는 인접 두 면의 안쪽 평행이동 교점을 따릅니다.
합산 전·후의 모든 경계 행렬과 전체 행렬의 각 항이 두 차분에서 큰 절댓값 대비
1e-4 이내로 일치해야 합니다. 작은 상호 항에 분모 하한을 넣지 않으며 정확한
두 0은 일치로 봅니다. 대칭·양의 준정부호·대수적 전류 보존도 별도 검사합니다.
반환 `parts`는 작은 차분폭의 결과입니다.

이는 **차분폭 안정성 검사이며 패널·외곽 수렴이나 절대 저항 오차 보증이 아닙니다.**
패널 수, 접지 Fourier 해상도, 외곽 영역을 독립적으로 확인해야 합니다.
유한 패널 전류를 제곱한 값과 유한 패널 정전용량을 미분한 값은 다를 수 있습니다.
비교할 때 양쪽 관측값을 보존합니다. 공유 솔버의 원래 기하 제한·내부 적분 기준은
유지하며, 미지원·미해상도 입력은 임의 대체 없이 거부합니다.

공유 풀이 횟수는 `1 + 4 * (도체 수 + 1)`입니다. 면당 패널 1~256,
총 패널 2048 이하, 접지 모드 64~4096, 보간 차수 10·12·14·16을 사용합니다.
이 명시 API의 기본 보간 차수는 16입니다. 패널 수가 많으면 여러 조밀 행렬 풀이의
비용이 커집니다. 요청 제어값을 자동으로 늘리지 않습니다.

불변 결과에 `step_m`, 합산된 두 `step_parts`, 합산 전 `boundary_step_parts`,
모든 `samples`를 보존합니다. 각 표본에는 정확한 요청·유전율로 나눈 정전용량·
솔버 진단값이 있습니다. `request.arguments()`는 독립 JSON 호환 복사본을 만듭니다.
`PanelShapeCurrentError`에는 완료한 표본, 해당하면 실패한 필드 요청, 차분·양성
검사 실패 시 두 단계 행렬을 남깁니다. 사용자 중단은 그대로 전파합니다.

```python
from sipi import CrossSection, Layer, Trace
from sipi.panel_shape_conductor import panel_shape_current_factors

section = CrossSection([Layer('uniform', .01105, 4.)],
    [Trace('signal', 0., .0008, .0008, thickness=35e-6)], .02)
factors = panel_shape_current_factors(section,
    panels_per_edge=32, ground_modes=1024)
assert factors.names == ('signal',)
assert len(factors.samples) == 9
assert factors.diagnostics['step_relative_change'] <= 1e-4
assert factors.current_error <= 1e-10
```

`panel_shape_conductor_loss_by_boundary`는 기존 경계별 금속·코팅·거칠기 법칙을
이 적분 계수에 적용합니다. 표피 깊이·표면 섭동 제한을 유지하며 체적 와전류 솔버가
아닙니다. 모든 reference 표면은 같은 재료를 사용합니다. 면마다 다른 금속이나
임의 국소 경계 임피던스에는 별도 계약이 필요합니다.

검증은 단일·대칭·비대칭·얇고 가까운 직사각 선로의 별도 세분 기준, 평면 위 원형선의
독립 영상 해석해, 다각형 법선·스케일·순서·접지 전위와 실패 입력 보존을 포함합니다.
영상해 비교의 작은 외곽 상자는 조건을 충족하지 못했고, 별도로 확대해 확인했습니다.
이 근거로 임의 다각형·실측 동박·네이티브 플랫폼·전체 제품 정확도를 주장하지 않습니다.
