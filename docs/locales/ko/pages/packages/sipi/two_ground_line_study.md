# 양면 접지 선로 물리량의 제조 공차 연구

[English](../../../../../packages/sipi/two_ground_line_study.md)

`TwoGroundLineQuantityStudyDocument`는 `sipi.two-ground-line-quantity-study/1`을
저장합니다. 단선 `z0` 원본은 `impedance_real`(Re(Zc), Ω) 또는
`attenuation`(Re(gamma), Np/m)을 선택합니다. 쌍 `z_diff_forward` 원본은
`differential_forward_impedance_real` 또는 `common_forward_impedance_real`을
선택합니다. 별도 Ic=0/Id=0 여기에서 전체 특성 행렬 Re(Zdd)/Re(Zcc)이며 독립 모드·
유한 단자 임피던스·삽입 손실이 아닙니다. 두 값을 함께 얻으려면
[쌍 공차](two_ground_pair_study.md)를 사용합니다.

영문 예제는 장 계산 없이 준비합니다. `study.analyze(max_evaluations=3)` 또는
공통 저장 실행으로 계산합니다. 길이는 m, 주파수는 Hz입니다. 길이0·네트워크 기준50Ω
선로를 만들며 선택한 특성 임피던스와 감쇠는 이 기준 임피던스에 의존하지 않습니다.
study/3 또는 /4의 순서 있는 기하·재료 표본과 제약을 보존합니다. 표면별 금속과 패널
설정은 고정입니다. 정규 표본은 한 변수일 때도 [[1.]] 상관 행렬을 명시합니다.
누락·추가·중복·비유한 JSON 필드는 거부합니다.

장 계산 전에 신호 개수·금속 법칙·표피 깊이·남은 코어 조건을 검사합니다. 명목 입력이
유효해도 모든 표본의 유효성을 보장하지는 않습니다. 모든 표본 생성과 예산 검사는
풀이 전에 끝냅니다. 중복도 각각 시도하고 실패 뒤 다음 표본을 진행하며 표본을 잘라내거나
재추출·삭제하지 않습니다. 각 행에 원 표본·해석된 기하/재료·정확한 선로 입력·물리량
또는 실패 단계·원인·완성된 전류/메시 근거를 남깁니다. 모든 행이 성공해야 기술 통계를
제공하며 수율이나 신뢰구간의 주장이 아닙니다. 부분 실패 실행은 `incomplete`이고
요청·기록·프로젝트를 다시 열어도 계산하지 않습니다. 중단은 전파합니다.

기존 FEM 공차의 물리량 진단과 순서 보존 루프에 선로·오류·행·결과 타입을 명시적으로
연결합니다. 전류법이 FEM으로 바뀌는 것이 아니며 [양면 패널](two_ground_panel_line.md)과
고정 공유 기능이 필요합니다. 기존 계산법·schema의 계산과 거부 조건은 유지합니다.

등록된 유한 영역 검사는 2GHz에서 편심 스트립라인 선폭 .55/.60/.65mm, 변당
64/128/256 패널입니다. 인접 R/L/C0 변화는 상대0.01·절대0을 두 번 모두 만족해야
합니다. 각 단계의 스칼라 임피던스와 전파는 복소 sqrt(Z/Y), sqrt(ZY)로 독립 비교합니다.
이로써 외곽 수렴·실측 손실 정확도·모든 단면/주파수나 다른 플랫폼을 입증하지 않습니다.
체적·유전체 세분은 선로 추출의 별도 기준으로 남습니다.

[한 변수 목표 역산](two_ground_line_goal.md)은 같은 선로 물리량을 사용하고
체적·패널·joint 세분을 각각 요구합니다.
