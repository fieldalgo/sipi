# 선형 모서리 전류의 유한 비교 저장

`sipi.two_ground_linear_corner_face_resolution_document`의
`TwoGroundLinearCornerFaceResolutionDocument`는
`sipi.two-ground-linear-corner-face-resolution/1` 스키마를 사용합니다.
명시적 선형 모서리 면별 선로, 모든 세분화 패널 설정, 외곽 선로 문서, 세분화 계수,
전체 선로 평가 한도와 선택한 SI 상대·절대 허용치를 저장합니다.
[유한 해상도](two_ground_linear_corner_face_resolution.md)를 참고하세요.

정규화 단계에서 모든 계획을 장 계산 전에 검사하며 기존 스키마 바이트를 유지합니다.
알 수 없거나 중복된 키, 비유한 값, 잘못된 선로 형식, 빠진 절대 허용치와 지원하지
않는 단위는 거부합니다. 저장 요청·CLI·프로젝트가 같은 여섯 단계 계산을 사용합니다.

계산이 끝나도 불일치하면 완료·미승인 상태입니다. 형식 있는 실패는 원래 실패 입력,
전류·메시 근거와 완료된 앞부분을 보존합니다. execution-record/2는 재계산 없이
저장 계획과 그 앞부분을 대조하며 execution-record/1은 이 부분 실패 형식을 받지
않습니다. 사용자 중단은 전파합니다. 가져온 산출물 선언은 설치 파일 검증이 아닙니다.

전류와 메시 재사용은 이 작업 안에서만 정확한 키와 정해진 한도로 수행합니다.
기록하는 선로 평가 횟수를 줄이거나 기하·재료·표피 깊이·기능·자원 검사를 생략하지
않습니다. 유한 단계 간 일치를 제공하며 절대 오차 한계나 실측 정확도를 입증하지 않습니다.
