# 양면 접지 쌍 선로 임피던스 역산

[English](../../../../../packages/sipi/two_ground_pair_goal.md)

`sipi.two_ground_pair_goal`의 `seek_two_ground_forward_pair_impedances`는
[양면 접지 저장 선로](two_ground_panel_line.md)를 기존 제한된 두 매개변수 전방
임피던스 탐색에 연결한다. `dependencies.json`의 명시적 공유 기능이 필요하며 기존
추출 기본값은 그대로다. callable API는 factory를 저장하지 않는다. 별도
[저장 목표 문서](two_ground_pair_goal_document.md)가 템플릿 입력을 저장한다.

factory는 유한하고 증가하는 범위 안의 양수 매개변수2개를 받아
TwoGroundPanelTransmissionLineDocument를 반환한다. 선로는 순서가 있는 신호2개,
양수 주파수1개, 길이0이어야 한다. 탐색 중 주파수·신호 이름·패널 설정은 고정이다.
전체 복소 도체 좌표 특성 행렬을 전력 쌍대 혼합 기저로 바꾸고 별도 Ic=0/Id=0
여기의 Re(Zdd), Re(Zcc)를 목표로 한다. 모드 대칭을 가정하지 않고 비대칭 결합을
보존한다.

캐시되지 않은 factory·장·진단 시도를 모두 세며 실패와 최적화 탐침도 포함한다.
max_evaluations는 기존 [4,10000]이다. 선택 입력을 고정한 뒤 검사할3회를 예약하고,
세분할 때 factory를 다시 호출하지 않는다. 탐색 장 계산 전에 세분 입력 모두가
입력·자원 검사를 통과해야 한다.

- 체적 세분은 해석된 edge_size·far_size·grade를 반으로 줄인다.
- 패널 세분은 panels_per_edge를 두 배로 한다.
- 결합 세분은 두 변경을 함께 적용한다.

접지 모드·보간 차수·재료·경계 및 다른 설정은 그대로다. 패널 수128 초과는 기존
상한256 안에서 두 배로 할 수 없으며 전체 패널 상한도 적용한다. 각 세분 결과는
두 원래 절대 목표 오차를 만족해야 한다. 원래 상대기준0.005는 세분 대 원래 결과,
결합 세분 대 각 단일축 세분 모두에 적용한다. 실패를 평균이나 대체 계산으로
바꾸지 않는다. 유한 외곽 적절성·유일성·연속성·전역 최적값·실측 정확도는 별도다.

TwoGroundForwardPairDesign은 선택 매개변수·목표·값·전체 탐색 이력·선택 입력·실제
세분 결과3개를 보존한다. 직렬화 관측에는 선택·세분의 전류 기록과 유전체 메시
식별이 포함된다. ForwardPairGoalError는 시도 횟수·완료 이력·실패 입력·단계·원래
TwoGroundPanelLineError 원인을 보존한다. 중단은 실패 목표로 바꾸지 않고 전파한다.
시도 예산이 내부 풀이 수·시간·메모리 한도는 아니다.

독립 합성 모드 해와 매개변수 비례 변환, 정확한 고정 세분 입력, 장 계산 전 입장,
예약 예산, 식별 설정 변화 거부, 최종4단계 각각의 실패·중단을 검사한다.
등록 물리 연구는 원8×2mm 상자, 높이 중앙의 두께50um 대칭 도체, 기존 국소 적층
양극·35MS/m 음극 금속, 공통58MS/m 접지면, epsilon_r4/tan_delta.003,2GHz이다.
폭 범위.35~.5mm·간격.2~.4mm·초기.38/.28mm, 목표90/44.5Ω·허용오차각.1Ω,
패널128→256·최대64회를 사용한다. 원 연구 통과 여부는 동반 기록에 남긴다.
독립 행렬 제곱근 전방 임피던스로 선택·세분 RLGC를 대조한다. 제한된 수치 통과를
일반 기하나 플랫폼 검증으로 확대하지 않는다.
