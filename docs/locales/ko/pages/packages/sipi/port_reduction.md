# 명시적 수동 부하 포트 축약

`terminate_ports(network, loads)`는 지정한 포트에 수동 부하를 연결하고 남은
포트의 `LineNetwork`를 반환합니다. 입력은 바꾸지 않습니다. 구동 단자 해석과
달리 더 작은 네트워크의 S를 반환하며 소스 전압·단자 전류를 계산하지 않습니다.

```python
from sipi import rlgc_network, terminate_ports
line = rlgc_network([0, 1e9, 5e9], R=[[0]], L=[[250e-9]], G=[[0]],
                    C=[[100e-12]], length=.01, z_ref=50, names=['trace'])
open_end = terminate_ports(line, {'far:trace': 'open'})
reflection = open_end.s[:, 0, 0]
```

`loads` 값은 `'open'`, `'short'` 또는 유한 수동 복소 임피던스(Ω)입니다.
수치는 scalar 또는 주파수마다 하나인 1차원 배열이며 실수부가 음수일 수 없습니다.
수치 0도 단락입니다. 지정하지 않은 포트는 유지하며 자동 정합 종단은 없습니다.
적어도 하나를 종단하고 하나는 남겨야 합니다. 미등록 이름·문자열, 음의 저항,
bool·비유한 수치·잘못된 shape는 거부합니다. 무한대는 개방의 표기가 아닙니다.

남은 포트는 원래 순서·주파수·양의 실수 기준 임피던스·basis를 유지하며 map의
삽입 순서는 무관합니다. 지정 basis에서 부하를 적용하므로 mixed-mode 포트의 부하는
모드 부하이며 실제 단일종단 저항쌍을 추론하지 않습니다. 결과 배열은 읽기 전용
복사이며 기준 임피던스 변경·주파수 보간은 없습니다.

종단 포트 L, 유지 포트 R에서 대각 반사행렬 Γ를 사용해
`(I−Γ S_LL) a_L = Γ S_LR a_R`를 풀고
`S_RR + S_RL (I−Γ S_LL)^−1 Γ S_LR`를 반환합니다. 구현은 역행렬을 만들지 않고
선형계를 풉니다. 개방 Γ=1, 단락 Γ=−1, 유한 부하는
`Γ=(Zload−Zref)/(Zload+Zref)`이며 스케일링으로 overflow를 피합니다.
특이계·2-norm 조건수 >1e12·비유한 해·정규화 잔차 >1e-10은 오류입니다.
고립 공진을 해소하려고 정규화하거나 숨은 손실을 더하지 않습니다. 입력 S는
능동일 수도 있으며 수동 부하만으로 입력의 수동성·인과성을 보증하지 않습니다.

`tests/sipi/test_port_reduction.py`의 검증 범위는 다음과 같습니다.

- 정합 무손실 균일 선로의 `Γin=Γload exp(−2jβl)` 절대 오차 <=1e-12.
  DC 및 1/4·1/2파장 개방·단락 변환을 포함합니다.
- 이상적 3포트 접합에서 개방 분기→직결, 단락 분기→두 독립 단락,
  정합 shunt의 해석적 S 행렬.
- 비상호 5포트·서로 다른 기준 임피던스·동시 부하 세 개를 독립
  `scikit-rf.network.connect` 2.2.0의 순차 연결과 두 basis에서 절대 <=1e-10로
  비교합니다. 수동성·순서·복사·극단 유한 스케일·잘못된 입력·조건수 오류도 검사합니다.

샘플 네트워크와 1차원 선로의 항등식이며 세분할 메시가 없습니다. 3D 비아·패드·
안티패드·귀환 전류 전이·복사·실제 stub 불연속을 해석하지 않습니다. 기하 기반
선로 추출의 메시·물리 유효성 검사는 별도로 필요합니다. 이 Python API는 저장형
입력 스키마를 추가하거나 기존 회로 JSON을 변경하지 않습니다.
