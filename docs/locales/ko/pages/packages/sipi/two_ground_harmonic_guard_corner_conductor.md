# 두 활성 선로와 고정 전위 유한 가드

명시적 `sipi.two_ground_harmonic_guard_corner_conductor` 모듈은 다음 API를 제공한다.

- `two_ground_harmonic_guard_corner_current_factors(section, ...)`: 전체 경계 전류
- `two_ground_harmonic_guard_corner_face_current_factors(section, ...)`: 면별 전류
- `two_ground_harmonic_guard_corner_conductor_loss(section, frequency, ...)`: 전체 표면 금속 손실
- `two_ground_harmonic_guard_corner_conductor_loss_by_face(section, frequency, ...)`: 면별 금속 손실

유한 직사각형 또는 사다리꼴 `Trace`가 정확히 세 개이고, 정확히 하나만
`ground=True`여야 한다. 아래·위 평면은 접지, 옆 경계는 열린 조건이다.
두 활성 전류 좌표는 단면의 비접지 선로 순서를 따른다. 가드는 0 전위에
고정되며 유도 전류는 0이 아닐 수 있다. 부유 도체나 유한 종단 회로 모델이 아니다.

고정한 공유 API에 두 활성 인덱스를 직접 전달하며, 소비자에서 정전용량을
다시 축소하지 않는다. 전체 경계 순서는 두 신호선, 아래 평면, 위 평면,
가드다. 면 결과는 신호선당 네 면, 두 평면, 가드의 네 면 순서다.
사다리꼴을 포함해 각 선로의 면은 전역 좌표의 아래/위/왼쪽/오른쪽 순서다.
부호 있는 전류 적분과 가드 손실·비대각 결합항을 보존한다. C0 및 그 역행렬로
정하는 외부 인덕턴스는 기존 진공 자기 외부장 계약을 유지한다. 유전체 정보는
이 추출에 영향을 주지 않으며 비균일 전기장은 별도 계산이다.

네 함수 모두 `panels_per_edge=32`, `ground_modes=256`,
`interpolation_degree=24`를 기본으로 한다. 압축 두 기저 방식은 짝수 분할
10..512와 짝수 모드64..4096을 허용하지만, 전체 물리 패널512개·밀도 기저1024개
한도를 지킨다. 사각형 세 개는32분할에서312개,48분할에서504개 패널을 사용한다.
정수 범위 안이어도 전체 한도나 적분 조건 때문에 거부될 수 있다. 자동 재시도나
대체 솔버는 없다. 필요한 물리량별로 패널과 유한 외곽을 각각 세분해야 한다.

두 손실 함수에는 양의 주파수(Hz), `conductors`, `reference`,
`ground_thickness`(m)를 명시한다. `conductors`는 정확히 두 활성 이름에 대해
전체 손실에서는 `SurfaceMetal`, 면 손실에서는 `TraceFaceMetals`를 제공한다.
`ReferenceSurfaceMetals`에는 아래/위 법칙, `sides=None`, 정확히 가드 이름을
키로 하는 `conductors`가 필요하다. 전체 손실의 가드는 전체 표면 법칙 하나를
쓰며, 면 손실은 균일하게 펼칠 법칙 하나 또는 서로 다른 네 면 법칙을 받는다.
기존 표피 깊이·남은 금속 두께·코팅·거칠기 조건을 장 계산 전에 확인한다.
국소 평면 코팅·거칠기 법칙은 코팅 모서리, 금속 내부 확산, 실측 포일 형상을
분해하는 모델이 아니다.

R과 내부 L은 기존 복소 표면 임피던스와 물리 전류 Gram을 사용한다. 가드의
각 면과 두 포일을 포함한 재료 기여를 따로 보존한다. 네트워크는 외부 L과 내부 L을
한 번씩 더하며 두 전류 좌표·네 포트를 유지한다. 이 API 자체가 저장 선로 스키마나
목표 탐색을 추가하지는 않는다.

공유 결과와의 직접 일치, 물리 면 끝점·소유자, 0이 아닌 가드 전류, 보존·불변성,
기하/활성 순서 변경, 전체/균일 면 법칙 일치, 독립 평활 금속 수식·양의 소모 전력,
수동·상호 네트워크, 선택한 가드 면의 거칠기/코팅 변화, 바닥값 없는32/48 패널
비교를 검증한다. 단면·재료·제어 오류는 장 계산 전에 거부한다. 요청 범위 재사용은
기하·접지 표시·제어·솔버 식별을 포함하며 실패 계산은 저장하지 않는다.
기존 방법과 기본값은 바꾸지 않는다.

공유 장에는 별도의 사다리꼴 유한요소 및 Fourier 원형 독립 기준 근거가 있다.
등록 기하와 수치 조건의 통과가 임의 기하·실측·미검증 운영체제를 보증하지 않는다.
