# 두 접지면 요청 안의 메시 재사용

단일 주파수와 유한 주파수 격자의 쌍 목표 역산은 동기 요청 한 번 안에서
동일하게 성공한 단면 메시를 재사용합니다. 역산 밖의 직접 저장 선로 실행은
기존처럼 매번 계산합니다. 솔버, 메시 설정, 점 수 한도, 목표, 세분 판정과
평가 예산은 바뀌지 않습니다.

비공개 키는 형상, 도체 이름과 순서, 경계, 유전체 메타데이터, 모든 메시 설정을
포함한 정규화 단면 문서 전체와 메시 메서드 및 생성·변환 진입 함수의 동일성을
포함합니다. 매 조회 전에 메시 설정을 검사합니다. 주파수, 금속 법칙과 패널
설정은 다른 계산 단계의 입력이며 이 단면 메시를 바꾸지 않습니다.
체적 세분 설정이 달라지면 반드시 다른 메시를 생성합니다.

성공한 메시를 비공개 복사본으로 저장하고, 최초 호출자에게 원본을, 재사용
호출자에게 깊은 복사본을 반환합니다. 노드, 요소 연결, 경계·영역 정보,
재료 배열과 신호·접지 노드 집합을 유지합니다. 호출자의 변경은 저장본으로
전파되지 않습니다. 실패한 메시는 저장하지 않습니다. 캐시 복사의 메모리
할당이 실패하면 원래 직접 경로를 사용하고 실제 메시 실패는 원래 예외를 유지합니다.

요청마다 최대 두 개 메시, 합계 최대 64 MiB의 ndarray 배열 내용을 보관합니다.
이를 넘는 결과는 저장 없이 사용합니다. 이 한도는 Python 메타데이터, 임시
복사본, 솔버나 전체 프로세스 메모리의 한도가 아닙니다. 가장 오래 사용하지
않은 항목부터 제거하고, 정상 종료·예외·중단 때 정리합니다. 중첩 요청과
동시 동기 요청의 캐시는 각각 분리합니다.

고정된 결합 스트립라인 선택 입력에서 재사용을 끈 결과와 저장 실행 전체,
이력, 전류와 메시 기록을 대조합니다. 2 GHz 및 별도 2/3.5/5 GHz 격자에서
네 번의 시도는 유지하고 실제 메시 생성만 네 번에서 두 번으로 줄입니다.
체적·공동 세분은 같은 세분 메시를, 명목·패널 세분은 같은 명목 메시를
사용합니다. 이 반복 입력을 독립적인 메시 수렴 근거로 세지 않습니다.
기존의 독립 물리·세분 검증도 필요합니다. 실행 시간의 개선 배수, 다른 플랫폼,
임의 형상 정확도나 배포 지원을 뜻하지 않습니다.
