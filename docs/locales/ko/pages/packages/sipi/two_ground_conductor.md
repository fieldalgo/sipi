# 명시적인 양면 접지 표면 전류

[English](../../../../../packages/sipi/two_ground_conductor.md)

이 명시적 소비자는 `dependencies.json`의 정확한 공유 개발 리비전이 제공하는
`galerkin.laplace_two_ground.solve_two_ground_rectangle`를 사용한다. 기능이 없으면
대체 계산 없이 RuntimeError를 반환한다. 기존 추출 기본값은 그대로다. 공유 패키지를
고정 리비전에서 빌드해야 하며 같은 버전 번호만으로 호환 wheel을 식별할 수 없다.

`two_ground_current_factors`는 아래·위 접지, 열린 측면, 유한 두께의 볼록 신호 및
접지 도체를 가진 CrossSection을 받는다. 열린 측면은 유한 전기 쌍대 문제에서
법선 전속 0이며 무한 방사 경계가 아니다. 길이·폭·높이·두께는 m이다. 표면 순서는
입력 순서의 신호, 아래 접지, 위 접지, 입력 순서의 접지 도체다. 접지 도체는 전위
0이며 부유 도체로 처리하지 않는다. 신호 정전용량 주부분을 선택하고 전체 경계
전류 기저를 변환한 뒤 묶는다. 부호가 있는 전류 합은 0이다. `parts`는 기존 공통
귀환 그룹 형식을 유지하며 개별 표면 행렬도 따로 보존한다.

전류 계산은 균질·비자성 진공 쌍대다. 층 유전율과 국소 유전체 정보는 이 계산에
들어가지 않는다. 외부 인덕턴스·도체 손실과 합칠 C/G는 정확히 같은 기하·경계에서
추출해야 한다. 공간적으로 변하는 외부 투자율을 풀지 않는다. 도체의 국소 투자율은
기존 금속 표면 법칙에 속한다.

`two_ground_conductor_loss`에는 신호별 SurfaceMetal과 명시적인
ReferenceSurfaceMetals가 필요하다. 위·아래 법칙을 지정하고 측면 법칙은 없으며,
접지 도체 이름을 정확히 지정한다. 법칙은 전체 도체 둘레 또는 접지면에 적용한다.
신호·접지 도체의 면별 법칙은 이 진입점에서 지원하지 않는다. 양면 접지는 명시한
공통 `ground_thickness`를 기존 최소 치수 제한에 사용한다. 서로 다른 접지면의
전도도·투자율과 기존 국소 거칠기·적층 도금 모델을 합성하며 새 금속 확산 방정식은
아니다. 모든 재료 및 남은 코어의 표피 깊이 조건을 장 계산 전에 확인한다.
표피 깊이는 남은 최소 도체 치수의 1/5 이하여야 한다. 기존 적층 법칙의 거칠기
동시 사용 금지도 유지한다.

표면 k별 `R = sum(real(Zs[k])*Q[k])`,
`L_internal = sum(imag(Zs[k])*Q[k]/omega)`이다. 결과는 주파수·금속 순서·부호 전류·
표면별 Q·표피 깊이·거칠기 계수·표면 임피던스를 불변 배열로 보존한다. 네트워크
메서드는 외부·내부 L을 합쳐 기존 RLGC 계산기를 사용한다. 상반성·수동성 검사는
도체 손실의 절대 정확도를 입증하지 않는다.

패널 수·접지 모드·보간 차수는 공유 API로 명시 전달한다. 2048패널 자원 한도와
전류·접지 전위 1e-10 기준을 유지하며 공유 행렬·접지 세분·조건수 제한도 적용한다.
등록된 네 단면 및 유한 넓은 상자를 저장 독립 P4 참조와 비교한다. 16/32mm 참조는
거친 P4이며 새로 세분한 참조가 아니다. 비대칭 쌍 선로는 차수14를 명시하며 이전
차수12 실패를 보존한다. 추가 접지 도체·서로 다른 접지면 시험은 대수 변환과
표면 법칙 불변식을 확인하는 것이며 새 메시·외곽 수렴을 뜻하지 않는다.
검증 범위는 유한하며 실측·모든 기하 정확도·새 플랫폼·브라우저·EXE를 보증하지 않는다.
