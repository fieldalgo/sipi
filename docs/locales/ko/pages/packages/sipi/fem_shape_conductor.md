# 명시 FEM 형상 에너지 전류

`fem_shape_current_factors(mesh, signals, ground)`는 진공 P1 전계 에너지의
기하 미분으로 전체 경계별 전류 에너지를 계산합니다. 외부 galerkin의 조립,
Dirichlet 및 정전용량 API를 사용합니다. 명시적으로 선택하는 방식이며 기존
표면전류 API와 저장 선로의 기본 계산은 바뀌지 않습니다.

단위 길이 방향 신호 전류에 대한 행렬 단위는 1/m입니다. `parts`는 신호 이름
순서와 모든 접지면을 합친 마지막 그룹을 따릅니다. 위·아래 접지면과 유한 접지
패턴을 함께 포함할 수 있지만, 개별 동박 면이나 서로 다른 접지 재료는 분리하지
않습니다.

```python
import numpy as np
from galerkin import rectangle_mesh
from sipi import fem_shape_current_factors

mesh = rectangle_mesh(.002, .001, 8, 4)
current = fem_shape_current_factors(
    mesh, {'signal': mesh.boundary['top']}, mesh.boundary['bottom'])
np.testing.assert_allclose(current.parts[:, 0, 0], [500., 500.], rtol=1e-10)
assert len(current.samples) == 16
```

선택한 금속 경계에서는 유전체 바깥쪽 법선 속도를 1, 나머지 경계에서는 0으로
줍니다. 경계 꼭짓점에서 대칭 법선 이등분식을 사용하므로 거의 평행한 법선의
행렬 계수 판정이 불필요한 접선 이동을 만들지 않습니다. 경계는 manifold여야
하며 꼭짓점마다 경계 변이 정확히 두 개 있어야 합니다. 모든 도체 절점은 자신의
유전체 경계를 이루어야 하므로 내부 두께 0 스트립은 거부합니다. 신호 1~4개,
최대 절점 300,000개·삼각형 600,000개를 허용합니다. 진공은 등방성·비자성이며
개방 경계는 절연 조건입니다.

두 가지 양의 조화 연장으로 경계 이동을 내부에 전달합니다. 보조 계수는 절점
중심에 대한 `1 + 0.5*r²/R²`이며 R은 최대 절점 반경입니다. 동일 진공 정전용량으로
정규화한 전계 에너지의 형상 미분을 각각 적분합니다. 첫 연장의 결과를 `parts`로
제공하며 두 결과는 `extension_parts`에 보존합니다. 평균화하거나 양의 준정부호
행렬로 투영하지 않습니다.

매 호출마다 `h = min_edge * 1e-3` 및 `h/2`의 양·음 이동, 두 연장, 모든 경계
그룹에서 진공 정전용량을 다시 풉니다. 변형 전계 풀이 전에 모든 변형 삼각형의
부호 있는 면적이 양수인지 검사합니다. 정전용량 요청 `8*(N+1)`회, 원 전위 기저
호출 2회, 스칼라 속도 풀이 `4*(N+1)`회를 사용합니다. 정전용량 요청마다 N개의
전위 기저를 풀므로 요청 한 번이 스칼라 선형 풀이 한 번이라는 뜻은 아닙니다.

두 유한차분과 에너지 미분의 일치는 분모 하한 없이 항별 상대 1e-4로 검사하며,
두 이동 크기 사이에도 같은 기준을 적용합니다. 두 연장의 차이는 경계별 전체
행렬 기준 1e-3 이하여야 합니다. 법선 속도 잔차는 1e-12, 속도 잔차·상호성·크기로
정규화한 양의 준정부호 검사는 1e-10입니다. 전체 에너지는 양의 정부호여야 합니다.
이는 수치적 일관성 검사이며 메시·외곽 수렴, 작은 상호항의 정확도, 실측 기판
정확도 또는 후속 금속·거칠기 법칙의 유효성을 보장하지 않습니다.

`base`에 원 P1 기울기 에너지, 부호 있는 전류 적분과 C0를 보존합니다.
`current_integrals`와 `current_error`는 여전히 이 원 기울기 계산을 가리키며,
새 에너지에서 부호 있는 전류를 추정한 값이 아닙니다. 작은 전류 잔차로 저항
오차를 제한할 수 없습니다. `L_external`도 동일 C0를 사용합니다. 메시 해상도와
유한 외곽 크기를 별도로 검증해야 합니다.

`FEMShapeCurrentError`는 단계, 가능한 경우 완료된 원 base, 에너지 배열, 부분
유한차분, 완료 정전용량 표본, 실패 표본 주소와 진단값을 보존합니다. 주소는
`(extension, group, level, sign, displacement_m)`입니다. 기하 입력 거부는 전계
풀이 전에 발생하며 중단 예외는 그대로 전파합니다. 실패한 비유한 관측도 진단을
위해 예외에 남지만 수락 결과나 JSON 데이터가 아닙니다.

관련 시험은 평행판·동축 해석식, 독립 scikit-fem 12.0.2의 P2 전위·체적 에너지,
기하 변환, 닫힌 차동 선로의 메시 세분 및 3·4신호 순서를 비교합니다.
scikit-fem은 BSD-3-Clause 시험 의존성이며 실행 의존성이 아닙니다. 독립 도구
대조와 메시·외곽 수렴은 별개입니다. 다른 운영체제·브라우저 Worker·무설치
실행 파일은 정확한 산출물로 별도 검증해야 합니다.

큰 두 사례의 독립 P2는 [보존한 기준 관측값](fem_shape_references.md)을 사용합니다. 제품 전류와 유한차분은 여전히 실제 실행하며 비교 기준을 유지합니다.
