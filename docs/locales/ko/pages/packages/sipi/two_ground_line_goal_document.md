# 양면 접지 한 변수 설계의 저장 입력

[English](../../../../../packages/sipi/two_ground_line_goal_document.md)

`TwoGroundLineQuantityDesignDocument`는 엄격한
`sipi.two-ground-line-quantity-design/1`을 저장합니다. 중첩된
[선로 물리량 공차](two_ground_line_study.md), 목표·절대 허용오차·최대 시도로
[제한된 직접 역산](two_ground_line_goal.md)의 재현 가능한 factory를 만들며 콜백을
직렬화하지 않습니다. 영문 예제는 준비·정규화만 하고 장 계산은 하지 않습니다.

원본은 count2인 sweep과 양수·비퇴화 범위 변수 하나여야 합니다. count2는 양끝점을
정의할 뿐 목표 탐색 전에 표본을 먼저 계산하지 않습니다. study/3 또는 /4의 기하·
재료 바인딩과 고정 피치·접지 간격 변환을 보존합니다. 선택 물리량에 따라 단선/쌍의
신호 개수와 목표 단위가 정해집니다. 임피던스 실수부는 Ω, 감쇠는 Np/m입니다.
목표는 양수이며 감쇠만0을 허용하고 절대 허용오차는 양수입니다.

명목·양끝·중점의 입력과 체적만·패널만·joint 세분을 사전 검사합니다. 범위 내부의
유효성이나 목표 달성 가능성을 보장하지는 않습니다. 누락·추가·중복·비유한 필드를
거부하며 저장 입력은 분리된 스냅샷입니다.

`design.solve()`와 `execute_saved(design.dumps(), max_evaluations=40)`는 같은
직접 알고리즘을 사용합니다. host 예산은 장 계산 전에 저장된5..10000 시도 예산을
포함해야 합니다. 세 시도를 세분에 예약하고 실패도 세며 원 절대 목표와 모든0.005
상대 기준을 유지합니다. 선택·세분의 정확한 동결 입력, 전류·유전체 메시, 이력과
물리량을 남깁니다. 숨은 선행 공차 계산·대체 factory·자동 재시도를 하지 않습니다.

실패 실행은 직접 목표 오류·형식화된 부분 선로 원인·시도 수·완성된 장을 보존합니다.
중단은 전파합니다. 요청·기록·프로젝트는 재계산 없이 입력/결과를 정규화·결합·복구합니다.
기존 CLI 검증/실행도 같은 registry를 사용합니다. 브라우저 표시·Worker 검증·Windows
패키징은 별도 작업입니다.

등록된58Ω 저장 사례는 직접 사례의 편심 기하·재료/금속·범위·주파수·패널/메시·40시도를
정확히 사용합니다. 선택과 세 세분의 입력/결과를 직접 사례와 비교하고 소스·설치본
영수증도 비교합니다. 이는 저장/실행 일관성 검사이지 새로운 독립 물리 정확도의 근거가
아닙니다. 외곽 적합성·실측 정확도·생산 수율은 별개입니다.
