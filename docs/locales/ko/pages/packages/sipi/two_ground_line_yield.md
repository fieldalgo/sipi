# 양면 접지 선로 물리량 규격 만족 확률

[English](../../../../../packages/sipi/two_ground_line_yield.md)

`TwoGroundLineQuantityYieldDocument`는 엄격한
`sipi.two-ground-line-quantity-yield/1` 입력을 저장합니다.
[물리량 공차 문서](two_ground_line_study.md)에서 단선 Re(Zc), 감쇠 Re(gamma),
쌍의 순방향 Re(Zdd)/Re(Zcc) 중 한 값을 선택합니다. 상하한은 경계를 포함하며
단위는 Ω 또는 Np/m입니다. 완료된 감쇠는 0을 허용하고 임피던스는 양수여야 합니다.
두 값을 동시에 제한하려면 [공동 규격 평가](two_ground_pair_yield.md)를 사용합니다.

영문 예제는 풀이 없이 입력을 준비합니다. `assessment.analyze(max_evaluations=4)`
또는 공통 저장 실행 API가 원래 순서대로 네 번 계산합니다. 네 표본은 사용 계약을
보이는 예이며 생산 수율을 규명하기에 충분한 표본이 아닙니다. 별도 금속 법칙,
기하·재료 표본, 전류 패널과 유전체 메시 설정은 원 입력을 보존합니다.

uniform/normal iid 표본만 허용하며 같은 행 안의 변수 상관은 허용합니다.
sweep/corners는 거부합니다. 한 개 이상의 한계가 필요하고 신뢰수준은 (0,1),
선택적인 최소 만족 확률은 [0,1] 범위입니다. 표본을 자르거나 재추출하지 않습니다.

`assess_two_ground_line_yield(study_result, minimum=..., maximum=...)`는 이미
계산한 행을 풀이 없이 평가합니다. 물리량, 변수 이름, 재생성한 원 표본 벡터,
순서와 실패 정보를 확인합니다. 이 구조 검사는 수동으로 만든 결과의 진위를
보증하지 않습니다. 완료된 행은 모든 지정 한계를 만족해야 통과합니다.
미해결 행도 원 분모에 남기므로 관측 비율은 통과/전체와 (통과+미해결)/전체
사이에 있습니다. 정확 Clopper–Pearson 구간은 모든 미해결 표본의 가능한 분류를
포괄하며 전부 미해결이면 [0,1]입니다. 신뢰 하한이 목표 이상이면 pass,
상한이 목표 미만이면 fail, 나머지는 undetermined입니다. 구간은 지정한 모델의
iid 표본 불확실성만 다루며 수치 오차, 재료·분포 불일치, 적응 선택, 측정 오차를
포함하지 않습니다. 실측 생산 수율이 아닙니다.

부분 실행은 incomplete로 저장하며 원 표본·실패 단계/원인과 완료된 전류/메시
근거를 유지합니다. request/record/project 재열기는 다시 풀지 않고 중단 신호는
전파합니다. 기존 line-yield 검사·통계 본문은 그대로 재사용하되 새 모델의
study/parser/result 형식을 명시합니다.

검증은 독립 유한 이항 꼬리 역산, 경계 포함, 0 감쇠, 미해결 분류의 모든 완성,
손상 행 거부와 풀이 없는 복원을 포함합니다. 등록된 유한영역 실물은 2GHz
편심 스트립라인, seed17, 폭 .55–.65mm uniform 네 표본, 한계 57–59Ω,
신뢰 .95와 최소 확률 .8입니다. 실제 원행을 남겨 독립 분류하고 소스·설치본
receipt를 대조합니다. 이는 통계 연결 검증이며 패널·체적·외곽 수렴이나
실측 정확도·다른 플랫폼 검증을 대체하지 않습니다.
