# 대칭 쌍 선로의 모드 투영

`LineParameters.even_odd()`는 실수 무손실 준 TEM 행렬 `C`, `C0`, `L`을
사용합니다. 각 행렬 `M`의 짝수·홀수 모드 투영은 다음과 같습니다.

```text
M_even = (M00 + M11)/2 + M01
M_odd  = (M00 + M11)/2 - M01
Z_mode = sqrt(L_mode / C_mode)
eps_eff_mode = C_mode / C0_mode
```

구현은 `M00/2`, `M11/2`, `±M01`의 세 항을 보상 합산으로 한 번에
더합니다. 대각항 평균을 먼저 반올림하면 상호항과 상쇄된 작은 투영에서
유효한 부분이 손실될 수 있습니다. 이 변경은 그 산술 오차를 줄이며,
필드 해·메시·재료 모델·역산 잔차 정의를 변경하지 않습니다.

두 신호 도체와 자기항 대칭성 검사는 그대로 적용됩니다.
`z_diff = 2*z_odd`, `z_common = z_even/2` 관계도 유지됩니다.
비대칭 쌍을 대칭으로 취급하거나 일반 다도체 특성 행렬 계산을
대체하는 기능이 아닙니다.

`tests/sipi/test_modal_projection.py`는 입력 부동소수점 행렬의 정확한
유리수 투영과 200자리 십진수 제곱근·비율을 독립 기준으로 사용합니다.
상쇄가 큰 양의 정부호 행렬, 신호 순서 교환, 입력 보존을 포함합니다.
이 검사는 산술 계산을 분리해 검증하며 물리 정확도·메시/외곽 수렴이나
플랫폼 간 역산 탐색 이력의 동일성을 보장하지 않습니다. 기존 필드·독립
참조 비교와 역산 검증은 계속 필요합니다.
