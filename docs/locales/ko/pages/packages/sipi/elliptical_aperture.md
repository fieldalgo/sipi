# 타원형 개구의 국소 정전용량 행렬

`EllipticalAperture`는 축에 정렬된 타원형 접지 경계 안의 원형 PEC 도체 1개 또는
2개에 대해 복소 Maxwell 정전용량을 단위 길이당 계산합니다. 유전체는 균질하며
meshine 다각형 메시와 Galerkin 정전계 에너지 조립을 재사용합니다. 두 도체의 크기가
같거나 다른 경우를 모두 지원합니다.

```python
from sipi import RoundConductor, EllipticalAperture, ApertureSectionDocument

section = EllipticalAperture(
    width=1.20e-3, height=0.80e-3,
    conductors=[
        RoundConductor("p", diameter=0.28e-3, x=-0.25e-3),
        RoundConductor("n", diameter=0.22e-3, x=0.25e-3, y=0.03e-3),
    ],
    eps_r=3.96, tan_delta=0.03,
)
document = ApertureSectionDocument(section, mesh={
    "size": 25e-6, "angular_divisions": 256,
})
restored = ApertureSectionDocument.loads(document.dumps())
print(restored.section.names)
print(restored.analyze())             # complex Maxwell matrix, F/m
print(section.mixed_capacitance(**restored.mesh_options))
```

길이는 모두 미터입니다. `width`, `height`는 **전체 축 길이**, `diameter`는 도체의
지름입니다. 타원 중심은 `(0, 0)`이며 각 도체의 중심을 명시합니다. 이름은 고유한
비어 있지 않은 한 줄 문자열이고 `ground`는 예약어입니다. 도체는 1개 또는 2개입니다.

반환 행렬은 입력 도체 순서를 따르며 서로 다른 자기 항과 상호 결합을 유지합니다.
균일 스칼라 계수는 전위장을 바꾸지 않으므로 진공 행렬에 `eps_r*(1-j*tan_delta)`를
곱합니다. 시간 규약은 `exp(+j*omega*t)`입니다. 상대 유전율은 양수, 손실 탄젠트는
음이 아닌 값이어야 합니다. bool·비유한 값을 거부하고, 차원이 있는 요소 면적을 표현할
수 없거나 C가 비유한 값 또는 실수부가 양의 정부호가 아니면 오류를 반환합니다.

출력은 국소 **C′ [F/m]**입니다. 총 패드 정전용량, 평면 간격, 자기 귀환 경로,
인덕턴스, 임피던스, 도체 손실, 3차원 비아 전이를 추정하지 않습니다. 타원은 명시한
기하이며 다른 oval이나 공유 antipad 치수로 자동 변환하지 않습니다. 이 검증 오차를
실제 전이·다른 기하 규약·측정 소자의 정확도로 해석할 수 없습니다.

## 차동·공통 좌표

두 도체의 `mixed_capacitance()`는 `(차동, 공통)` 순서의 전체 행렬을 반환합니다.

- `Vd = V1 - V2`, `Vc = (V1 + V2)/2`;
- `Qd = (Q1 - Q2)/2`, `Qc = Q1 + Q2`;
- `T = [[0.5, 1], [-0.5, 1]]`, `C_mixed = T.T @ C @ T`.

이 변환은 `V.conj().T @ Q`를 보존합니다. 도체 교환에 정확히 대칭인 경우
`Cdd = (C11-C12)/2`, `Ccc = 2*(C11+C12)`입니다. 도체별 odd/even 정전용량과
정규화가 다릅니다. 비대칭 쌍의 혼합 교차 항도 유지하며, 이 좌표가 독립 전파 모드라는
뜻은 아닙니다. 계산 행렬을 대칭 쌍으로 평균하지 않습니다.

## 기하·메시·입력 저장

`mesh(size=None, angular_divisions=128)`는 미터 단위 공유 메시, 입력 순서의 신호
절점 집합, 접지 절점을 담은 `MeshedAperture`를 반환합니다. 기본 `size`는 긴 축 길이의
1/48입니다. `size`는 전위장 해상도, 16 이상 정수인 각도 분할 수는 타원과 원
**모두**의 다각형 근사를 제어합니다. 경계 변을 세분해도 직선으로 유지합니다.
두 제어값을 따로 보강해야 합니다. 외곽 접지는 물리 경계이며 열린 영역 절단 상자가
아닙니다.

생성 시 이름·숫자·외접 상자 간격·도체 겹침을 검사합니다. `mesh_settings()`는 내부
원판 전체가 외곽 내접 다각형의 모든 안쪽 반평면에 포함되는지 검사합니다. 긴 축으로
정규화한 간격은 `32*machine_epsilon`보다 커야 합니다. 보수적인 조건이므로 정확한
타원 안에 들어가는 원도 거부할 수 있으며, 이때 각도 해상도를 높입니다. 중심만 들어가고
둘레가 밖으로 나간 원도 거부합니다. 전위장 계산 전에 검사가 끝납니다. 거의 접촉한
경우·극단적인 종횡비·매우 작은 도체는 개별 수렴 검증이 추가로 필요합니다.

메시의 홀은 이름이나 출력 순서와 무관하게 기하 순으로 정렬합니다. 요청한 도체 순서를
바꾸면 같은 메시에서 C의 순서만 바뀝니다. 별도로 메시를 만든 반사 기하는 정확히 같은
자기 항을 주지 않을 수 있으므로 이산화 오차와 대수적인 대칭을 구분합니다.

`ApertureSectionDocument`는 `sipi.aperture-section/1`로 미터 단위, 전체 축, 도체
이름·지름·중심, 유전 특성과 확정 메시 설정을 복사하여 저장합니다. 누락/알 수 없는 필드,
중복 JSON 키, 잘못된 기하, 미지원 스키마·단위를 거부하며 결과는 넣지 않습니다.
기존 [`CircularAperture`와 `sipi.circular-aperture/1`](circular_aperture.md)은 그대로입니다.
어느 입력도 임피던스 공차 문서로 취급하지 않습니다.

## 검증

독립 경계 적분은 상수 선전하 패널의 로그 Green 함수, 자기 패널의 해석적 적분,
다른 패널의 16점 Gauss 적분, 미지 상수 전위와 총 경계 전하 0 조건을 사용합니다.
세 기록 사례에서 경계당 패널 수 128→256에 따른 C 변화는 최대 0.0264%입니다.

| 사례 | 고운 FEM과 패널 기준의 상대 행렬 노름 차이 |
|---|---:|
| 편심 원형 개구: 축 0.8/0.8 mm, 도체 지름 0.28 mm, 중심 이동 0.2 mm | 0.0831% |
| 중심 원형 도체: 타원 축 0.73/0.53 mm, 도체 지름 0.28 mm | 0.0587% |
| 같은 도체 쌍: 타원 축 1.2/0.8 mm, 지름 0.28 mm, 중심 피치 0.5 mm | 0.1422% |

쌍의 차동 성분 차이는 0.1577%, 원형 해석해 오차는 0.0918%입니다. 사전 기준은
행렬/차동 비교 1%, 패널 세분과 원형 해석해 0.2%, 전위장/다각형 각각의 세분 0.5%입니다.
이는 사례 결과이며 보편적인 오차 상한이 아닙니다. 같은 메시에서 독립 scikit-fem 복소
조립을 `1e-9`로 별도 대조하며, 전하·전력 쌍대성, 도체 순서 교환, 메시 강체 회전,
2의 거듭제곱 크기 변환, 복소 재료 배율과 엄격한 저장 입력 재생도 검사합니다.
